# 2026-10-20 리포트 7차 점검

## 원인과 변경

- 첨부 00:36 보고서는 한국 ETF에 10/19 일봉이 있었으나 Yahoo 한국 지수 두 개는 10/16에서 멈춰 있었다. 지수 날짜의 합의를 시장 기준일로 사용하여 한국 종가 연결 비중이 24.6%로 축소됐다. UTC 날짜만의 문제는 아니었다.
- 생성 시각은 KST로 정규화한다. 거래소 일봉 날짜는 거래일 라벨이므로 UTC 순간으로 변환하지 않는다. 한국/미국 정규장 상태, 마지막 확정 종가, 진행 중 세션을 따로 표시한다.
- 한국 지수는 Naver `periodType=month`의 일별 자료로 최신 누락분을 보완한다. `day`는 분봉, `year`는 주간 집계일 수 있어 일봉으로 사용하지 않는다. 공급처 응답 날짜를 사용하며 누락된 거래일 가격을 만들어내지 않는다.
- 미국 장중은 별도 5분봉 일괄 조회를 사용한다. 조회 시각 이전에 완료된 봉만 사용하며 직전 미국 완료 세션의 종가가 있어야 일간 변동을 계산한다. 지난 미국 종가·3M·스타일·매크로 표에는 장중 봉을 섞지 않는다.
- 계좌 헤드라인은 각 시장 최신 확정 종가의 실제 등락 가중치다. 미국 장중 보유분과 다음 한국장 갭 시나리오는 별도로 표시하며 합산하지 않는다. 한국 종가보다 오래된 미국 하락을 다음 갭으로 재계상하지 않는다.
- 마감 뉴스와 진행 중 뉴스의 검색 창·중복 제거를 분리했다. 미국 장중 검색에는 영어 검색어와 해당 미국 날짜를 별도로 사용한다. 금요일 주제 기사가 월요일 같은 주제의 반등 기사를 지우지 않는다.
- 업종별 인과는 사실/해석(추정)/미확인으로 구분한다. 복수 시장의 AI 투자 불안 기사는 보도일과 건수를 함께 표시하는 공통 테마이며, 과거 업종 종가의 직접 원인으로 주장하지 않는다.
- Meta 공식 IR: 미국 10/21 마감 후 발표, 한국 10/22 새벽. 실적 콜 05:30 KST는 발표 분 시각과 다르다. 한국은행 공식 2026년 금통위 일정에는 10/22가 있다. FRED로 연결된 BLS 날짜는 반복 403 문구를 생략하고 표준 08:30 ET 시각 규칙과 예외 미확인을 표시한다.
- Census 소매판매 진단에는 HTTP 상태·비밀값을 제거한 파라미터·발표 확인 여부를 남긴다. 로컬 실조회에서 HTTP 302였으며 실제치/예상치를 만들어 채우지 않았다. FRED/ECOS 등 미설정 키도 정상 수집으로 취급하지 않는다.

## 이력 저장

기존 Supabase 서버 클라이언트에 계정별 저장소를 연결했다. `owner_email + us_session + kr_session` 키로 같은 거래일 쌍을 갱신한다. 실패 시 기존 로컬 사본으로 복구하고 영구 저장 미확인을 표시한다.

`docs/20261020_report_history.sql`은 준비만 했으며 실제 DB에 적용하지 않았다. Google 로그인은 Supabase Auth JWT가 아니므로 `auth.uid()` 기반 정책을 임의로 만들지 않았다. 직접 클라이언트 접근은 막고 기존 서버 전용 클라이언트의 모든 조회/쓰기를 검증된 로그인 계정으로 제한한다. SQL은 새 테이블 한 개를 추가하며 기존 데이터는 삭제하지 않는다.
