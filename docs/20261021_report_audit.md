## 확인 한계와 남은 항목

- 과거 US 10/20 / KR 10/19 쌍에는 원본 수집시각·출처가 저장되지 않았다. 현재 코드는 지수 관측 날짜에서 기준일을 만들며 UTC 날짜를 단순 차감하지 않는다. 과거 쌍이 생긴 정확한 원인은 당시 지수 응답이 없어 확정할 수 없다. 새 이력에는 재발 시 대조할 근거를 저장한다.
- 고정 관측값은 원자적 로컬 파일이다. 같은 디스크의 재실행/재시작에서는 유지되지만 Cloud 재배포 후 영속 보존은 보장하지 않는다. 이 전환에서 이전 일봉 기준과의 스트레스 비교는 보류한다.
- Census 요청 변수는 공식 변수 문서와 대조했다. HTTP 200만으로 발표치 수집 성공으로 처리하지 않는다. 허용된 응답 열/최대 두 행, 관측치 제외 이유, 안전한 요청 변수와 HTTP 상태를 기록한다. 임의 응답 원문이나 API 키는 기록하지 않는다. 사용자 Cloud의 실제 200 응답 본문이 없어 최종 원인은 아직 확정하지 못했다.
- 한국 수출은 미시도/성공 캐시/목록 요청/본문 요청/파싱 실패를 구분해 기록한다. 로컬 공개 조회에서는 목록 HTTP 200, 본문 ReadTimeout이 관찰됐다. 이는 Cloud의 동일 원인을 확정하는 증거는 아니다.
- 새 실제 계좌 리포트와 외부 통신 포함 2~3회 반복 측정은 사용자 재계산 후 확인해야 한다. 로컬 샘플은 합성 입력 검증이며 실제 새 시세나 계좌 분석 결과가 아니다.
