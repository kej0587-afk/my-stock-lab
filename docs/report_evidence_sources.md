# 시황 근거 연결

## 매크로

WTI·원/달러는 NY 16:00에 끝나는 5분봉으로 당일·직전 거래일·21미국거래일 전을 비교합니다. 실시간 5일 프레임 밖의 기준봉은 59일 이내 이력에서 보완합니다. 시각이 다른 일봉·가까운 봉으로 대체하지 않습니다. 검증된 공개가격 스냅샷만 캐시합니다.

## 컨센서스

`verified_consensus_20261021.json`은 Reuters 보도에서 확인한 **2026년 9월 발표 당시 설문**입니다. 사후 기사 확인값이며 시점별 백테스트 데이터가 아닙니다. 대상월·발표일·단위·전월비/전년비를 모두 맞추고, 발표 당시 실제치와 수정치가 달라지면 이 고정 설문 비교를 적용하지 않습니다. 다음 달에는 재사용하지 않습니다.

추가 자동 공급원은 Trading Economics의 `Forecast`(설문)입니다. `TEForecast`(자체 전망)는 컨센서스로 사용하지 않습니다. CPI 전년비·PPI 전년비·비농업고용·소매판매는 무료 공개 표에서 전체 발표일과 공식 관측월을 검증해 연결합니다. 최대 4개 페이지를 병렬 조회하고 15분 캐시합니다. 제공처별 설문값이 다를 수 있으므로 출처를 표시합니다. 권한이 없거나 정의가 불명확하면 미확인으로 둡니다.

필요한 경우 Streamlit Cloud의 Secrets 또는 로컬 비추적 secrets에만 설정합니다. 키를 채팅이나 Git에 넣지 않습니다. 유료 가입·결제는 자동으로 하지 않습니다.

```toml
[economic]
TRADING_ECONOMICS_API_KEY = "발급된 캘린더 접근 키"
```

## 기사 본문

수집은 자동 뉴스픽 생성 시에만 실행합니다. 공개 RSS 2개와 최대 4개 공개 본문을 제한적으로 읽고 캐시합니다. 로그인·유료벽·차단을 우회하지 않습니다. 개인·비상업적 RSS 이용 범위를 전제로 하며 상업 서비스나 재배포에는 각 제공처 이용 허락을 별도로 확인해야 합니다.

RSS 최근 120건에서 밀린 미국 새벽 기사는 확인한 원문 주소를 거래일별 보조 자료로 쓸 수 있습니다. `verified_article_sources_20261021.json`은 미국 10/20 세션만 포함하며 다른 거래일의 원인으로 재사용하지 않습니다. 미래 거래일의 원문 확보를 보장하는 유료 뉴스 피드를 대신하지 않습니다.

전체 본문은 파일·계좌 DB·외부 LLM으로 저장·전송하지 않습니다. 짧은 근거와 해시·출처·발행/수정 시각만 남깁니다. 제목·날짜가 맞는 실제 본문에서 확인한 사실과 경제적 전달 경로의 `해석(추정)`을 구분합니다. 제목만 읽은 기사에는 본문 해석을 붙이지 않습니다.

보유 연결은 업종·기초자산의 영향 경로입니다. 기사만으로 종목의 실제 수익 기여나 매매 허용을 확정하지 않으며 기존 판정·임계값은 변경하지 않습니다.
