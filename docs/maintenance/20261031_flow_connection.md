# 종목별 돈흐름 연결

## 원인

- 정밀관측소는 현재 세션의 레이더 스냅샷만 읽었다. 재부팅 직후나 레이더를
  먼저 실행하지 않은 세션은 가격 이력이 충분해도 미연결이었다.
- 레이더의 섹터/테마 대상 목록 밖 종목에는 연결할 행이 없었다.
- 레이더 행을 왼쪽 병합하면서 기존 종목 근거를 열 단위로 지워, 레이더에
  없는 종목의 자체 근거까지 사라질 수 있었다.

## 적용

| 경로 | 처리 |
| --- | --- |
| 개별 종목/ETF 원자료 | 이미 조회한 일봉으로 레이더 공통 메트릭 함수를 재사용. 추가 외부 조회 없음 |
| 같은 기준일 레이더 | 기존 후보군/판정/랭킹 보조를 유지. 최신 가격·거래량 날짜를 함께 확인 |
| 오래된/상충 레이더 | 유효한 같은 종목 근거가 있으면 사용하고 원래 레이더 날짜·판정을 별도 보존 |
| 양쪽 자료 모두 부적합 | 기존 대기 근거를 중립 자료로 덮어 실행 허가로 바꾸지 않음 |
| 단기 상장/자료부족 | 20봉 미만은 산출 보류. 3M/6M 등 부족한 기간은 부분연결과 미산출 사유 표시 |
| 거래량 누락 | 가격 로더의 기존 0 보정은 유지하되 누락 세션을 별도 기록. 돈흐름 계산에서는 결측으로 복원 |
| 코인 일봉 | 지표 계산의 300봉 제한 이전 전체 1년 자료를 사용. 주식의 252봉을 대신 적용하지 않음 |
| 정밀관측소/검토 ZIP | 같은 연결경로·기준일·일간/1M/3M 수익률·거래량 증감 표를 전달 |
| 전광판/오늘점검 | 동일 원자료 근거를 저장 후 공통 연결 선택기를 거침. 상세표에 연결경로·보완 사유 포함 |

후보 등급/임계값/점수식/기존 판정문구는 변경하지 않았다. 기존에 미연결이던
종목에 실제 돈흐름 제약이 생기면 게이트는 달라질 수 있다. 긍정 흐름으로
시장/비중/추세 방어를 해제하지 않는다. 자체 계산은 테마 순위나 실제 자금
순유입 금액을 만들어내지 않는다.

가격 원자료를 새로 조회한 것으로 표시하지 않으며, 지연된 원자료는 기존
가격 신선도 검사에 그대로 남는다. 레이더 전체 수집이나 컨센서스/공시
공급자의 누락을 이번 연결 수정이 모두 해결하는 것은 아니다.

## 검증

- 원 계산식과 메트릭 일치, 외부 호출 금지, 원본 불변, 인덱스/측정 ID 보존.
- 레이더 미실행·대상 밖 종목, 낡은/미래/상충 날짜, 거래량 누락과 실제 0 구분.
- 불완전 자료끼리 대체할 때 대기 근거 유지, 기존 시장방어 유지.
- 동일 입력의 전광판·오늘점검·정밀관측소 근거/게이트 일치.
- 화면과 검토 ZIP의 연결 표 일치, 원 판정에 같은 표를 중복 저장하지 않음.
- 로컬 MSFT 실제 자료에서 레이더 미실행 상태의 10/30 가격/돈흐름 연결 확인.
- 전체 오늘점검 소요시간 개선율은 측정하지 않았다. 별도 프로세스의 100개
  합성 일봉 계산은 예열 후 0.627초였으나 전체 서비스 측정값이 아니다.
- 집중 회귀 84개 통과(29.90초), 최종 전체 회귀 4,160개 통과,
  1개 건너뜀, 하위 테스트 18개 통과(193.95초).
- 독립 리뷰의 세 재현 사례(불완전 근거 대체/로더 거래량 결측/코인 기간 불일치)를
  수정 후 재현 검사로 재확인했다.

다음 단계의 외부자료 품질 감사에서는 연결 자체와 별도로 공시 보고기간,
애널리스트 대상 종목/예상치 단위/발표일 정합성을 확인해야 한다.
