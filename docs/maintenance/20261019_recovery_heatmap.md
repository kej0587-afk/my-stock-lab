# 10/19 시황 복구 및 대표주 히트맵

## 완료 범위

- `[economic]`의 FRED_API_KEY, CENSUS_API_KEY, ECOS_API_KEY 형식은 기존 코드가 지원한다. 로컬에는 세 키 모두 없으므로 Cloud 키의 유효성이나 실제 HTTP 실패 원인은 확인하지 못했다. 키 내용은 출력하거나 저장하지 않았다.
- Census 공식 변수 문서에서 `time_slot_date`가 유효함을 확인했다. 근거 없이 API 파라미터를 바꾸지 않았다. 보고서에서 키 감지 여부와 인증/HTTP/시간초과/통계항목 검증 오류를 구분한다.
- 검증된 CPI·수출·소매판매 관측치만 로컬 파일에 보관한다. 실패 시 마지막 성공값을 기준월·조회시각과 함께 stale로 표시한다. 미래/오래된 값은 복원하지 않으며 실패·키·계좌자료를 저장하지 않는다. 실패값으로 성공 캐시를 덮어쓰지 않는다.
- 한국 통계 API 누락/구월 자료 지연에는 공식 문서 확인값을 한시적으로 보완한다. 2026-11-03부터 사용하지 않는다. 실시간 API 응답과 구분한다.
- 계좌 대체 합산은 국내 미국지수 ETF의 한국 일간 기여를 제거하고 미국 기초지수 시나리오를 삽입한다. 미국 상장 ETF 자체 수익률에 레버리지를 다시 곱하지 않는다. 0167A0처럼 구성종목 기반 수치 시나리오가 없는 경우 합산에서 제외하고 연결 비중을 공개한다.
- 결론 → 보유 영향 → 시장 스토리 → 경제지표·업종 → 후보·일정·뉴스 순으로 정리했다. 기존 일간/갭 개별 합계는 유지한다. 보유 표는 기준일 실제/갭 시나리오/당일 실제/사유로 분리했다.
- 후보품질 원본을 우선 읽고 실행 게이트는 별도로 표시한다. 점수·매매 임계값은 변경하지 않았다.
- SOXX/XLK/IGV 뉴스는 미국 기준 거래일과 업종을 함께 확인한다. AI 시장 전반 보도는 개별 업종의 직접 원인이 아니라 시장 공통 맥락으로 표시한다. 한국 메모리 경쟁력 기사를 XLK/IGV 원인으로 연결하지 않는다.
- 뉴스 제목만 있는 경우 본문 요약으로 가장하지 않는다. 5bp 미만 금리 변화 해석에는 무관한 할인율 링크를 붙이지 않는다. CPI/PPI 해석을 구분하고 발표일 금리가 반대로 움직인 경우 이를 명시한다.
- 기존 중기 흐름 표(미국/국내/글로벌/테마, 반도체·AI)와 게이트 해제 기준을 축약해 복원했다. 결측 자료는 순위에 넣지 않는다.
- 시장판에 별도 대표주 보기: 국내 36개/미국 52개, 업종별 묶음·종목명·등락·기준일·개별 상세. 고정 대표 표본이며 전체시장/지수 구성/추천 목록이 아니다. 면적은 동일하며 시총 가중으로 가장하지 않는다.
- 히트맵은 선택한 시장·표시대상만 조회한다. 오늘점검 판정 대상이나 자동 조회 종목을 늘리지 않았다. 기존 5분 가격 캐시, 결측 및 장중/마감 분리는 유지한다.
- BLS 일정 페이지가 실패하면 설정된 FRED 키로 CPI·PPI·고용 공식 발표일을 보완한다. 정상 BLS 응답은 그대로 쓰고, FRED 성공값만 캐시한다. BLS 오류 및 대체 출처를 함께 표시한다. FRED가 제공하지 않는 발표 시각·대상월은 추정하지 않으므로 발표 수치에 날짜를 임의로 연결하지 않는다. [FRED 공식 API 명세](https://fred.stlouisfed.org/docs/api/fred/release_dates.html)

## 성능과 검증

첨부 performance (3)는 121.417초, 가격 조회 활성 구간은 89.822초이다. 구간들은 병렬로 겹치므로 합산하지 않는다. 이번 작업으로 오늘점검이 1분 안에 된다는 주장은 하지 않는다. 공개 경제지표의 마지막 성공 저장과 히트맵 분리 조회를 적용했으며, 새 Cloud 측정은 필요하다.

전체 회귀 1,174개 통과(43.33초), 기존 pykrx 경고 1개. 개별주 36/52개, 장중 음수·결측 보존, 조회 분리, 종목/ETF 전환, 원본 등급 표시, 대체 합산, 성공→실패→복구, 공식 문서 만료를 검증했다. BLS 실패 시 FRED 보완·날짜/대상월 구분·실패 재시도·키 비노출도 검증했다. 국내·미국 히트맵은 로컬 브라우저에서도 합성자료로 확인했다. 투자성과 백테스트나 Cloud API 실연결 검증이 아니다.

## 남은 항목

- Cloud의 Census/ECOS 실제 실패 원인 확인: 새 보고서의 안전한 진단 결과 필요. 키를 채팅에 전달할 필요 없음.
- 외부 저장소 이력 이전은 미구현. 로컬 성공값 보관은 재배포 영속성을 보장하지 않는다. 기존 경고를 숨기지 않았다.
- BOK/실적 캘린더 통합, 급락일 별도 뉴스 수집은 이번 범위에서 보류했다. FRED 일정 대체는 구현했지만 로컬에는 키가 없어 실제 인증 호출은 미검증이다.
- 빠진 뉴시스 기사에는 당시 원본 RSS 응답/필터 이력이 없어 시간창·상한·중복 중 어느 단계인지 단정할 수 없다.
- WTI 99.02와 101.41은 기존 자료상 동일한 10/16 CL=F 표기다. 원본 응답/선물 월물 식별자가 없어 월물 변경인지 공급처 수정인지 확정하지 않았다. 100달러 경계 +18점 임계값은 유지했다.
- 사용자 실제 계좌의 대체 합산은 새 계산 결과로 확인해야 한다. Markdown에는 개별 비중이 없어 -3.6%p를 검증할 수 없다. 제공 예시는 가상 비중을 명시한다.
