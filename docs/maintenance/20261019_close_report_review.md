# 10/19 16:18 리포트 한정 수정

매매 판정, 점수, 비중, 시장 게이트, 조회 제공처 우선순위는 변경하지 않았다. 집에서 반영한 기존 코드 위에 표시/자료 연결만 수정했다.

## 확인한 원인과 수정

- 히트맵: 개별주 36/52개는 이미 있었지만 기본 선택이 ETF였다. 대표 종목을 기본으로 변경했다. 이전 세션에서 ETF를 직접 선택한 상태는 유지된다. 배포 후 새 세션 또는 `표시 대상: 대표 종목`에서 확인한다. 전체시장/시총 가중 히트맵이 아니라 고정 대표 표본이다.
- 계좌 헤드라인: 한국 10/19 종가는 미국 10/16 이후이므로, 국내 미국지수 ETF를 오래된 미국 수익률로 다시 치환하지 않는 기존 계산은 유지했다. 그런데 제외 후 연결률 24.4%인 대체 합산을 제목에 올린 것이 표시 오류였다. 마감 후에는 최신 종가 합계가 우선이며, 연결 비중 90% 미만은 숫자 헤드라인에서 제외한다.
- 첨부 집계값 `-3.00%p/99.9%`를 선택하고 `-2.29%p/24.4%`는 제외하는 회귀를 추가했다. 실제 계좌의 개별 비중이 Markdown에 없어 합계 자체의 재계산은 하지 못했다. 생성 예시는 가상 비중을 명시한다.
- 개장 전/장중/마감 후/휴장 모드를 표시한다. 주말 및 명시된 휴장 플래그를 지원한다. 평일 특별휴장·수능일 변경시간을 자동 판정하는 거래소 캘린더는 아직 연결하지 않았다. 가격 미수집을 휴장으로 추정하지 않는다.
- 마감 후 보유 표의 중복 현재값 열을 제거했다. 나스닥 ETF는 `시나리오 -2.50% / 종가 -1.19% / 차이 +1.31%p`로 비교한다. 이는 시가 갭 예측 오차가 아니라 종가 등락과의 차이다. 직전 한국 거래일과 미국 기초자산 날짜가 다르면 비교를 보류한다. FX/선물 미반영은 표시한다.
- 0167A0의 마감 후 갭 위험 문구를 실제 종가 결과로 교체했다. 당일/직전 코스피 라벨과 다음 점검 시점도 분리했다.
- 마켓뷰 같은 날 마감 회고, 미국 AI 차입 우려 회고를 기준 세션에 연결한다. SOXX/IGV/XLK에는 제목 기준 기사 주장임을 표시한다. 한국 메모리 경쟁력 CXMT 기사를 DRAM 하락 원인으로 연결하지 않는다. 원문 본문을 읽은 인과 분석으로 가장하지 않는다.
- 한국 수출 전년비 및 이전 대비 차이를 요약에 포함했다. 한국 발표 반응은 한국 날짜의 코스피/원·달러로 분리했다. 공급처 환율 일봉이 아직 마감되지 않았으면 미수집이며 한국 종가 시각의 환율로 가장하지 않는다.
- 공식 문서 확인값은 `수동 보완값` 및 만료일을 표시한다. 자동 API 수집 성공으로 바꾸지 않았다.
- 한국 에너지/반도체 가격 기준일을 보고서 조회 대상에 포함하고, 2차전지의 기존 3M/가속도/상태를 병기한다. 반복되는 미확인 안내는 공통 한계 한 줄로 묶었다.
- 다음 CPI/PPI/고용은 7일 밖이어도 각각 가장 가까운 90일 내 발표일을 표시한다. FRED 날짜만 있으면 시간을 만들지 않는다. BLS 시각이 있으면 KST로 변환한다. [11월 공식 일정](https://www.bls.gov/schedule/2026/11_sched.htm): 고용 11/6, CPI 11/10, PPI 11/13.
- 물가 해석과 반대 금리 움직임이라는 문구에도 5bp 기준을 적용했다. 투자 판정의 금리 임계값 변경이 아니라 기존 보고서 해석 기준을 통일한 것이다.
- Census 로그에 HTTP 상태, 허용된 요청 항목, 오류 종류, 최신 관측월을 기록한다. 키/요청 URL/응답 본문/예외 원문은 기록하지 않는다. 응답이 없다고 미발표로 단정하지 않는다. Cloud 키 실제 응답은 로컬에서 검증하지 못했다.

## 이력 확인

`report_history.py`는 생성 날짜가 아니라 미국/한국 기준 거래일 쌍으로 저장한다. 10/19 오전 양쪽 최신 완료봉이 10/16이면 `2026-10-16/2026-10-16`, 마감 후에는 `2026-10-16/2026-10-19`가 된다. 생성 날짜를 잘못 저장한 것이라고 단정할 수 없다. 동일 기준일은 덮어쓴다.

Cloud 이전 파일이 제공되지 않아 비교가 비어 있는 원인이 재배포/계정 분리/이전 저장 부재 중 무엇인지 확정할 수 없다. 외부 DB 이전과 시나리오 오차의 거래일별 영구 저장은 이번에 구현하지 않았다. BOK/주요 실적 캘린더도 미연결 상태다. [한국은행 공식 일정](https://www.bok.or.kr/eng/main/contents.do?menuNo=400020)에서 10/22 회의를 확인했지만 자동 연동 완료로 표시하지 않았다.

## 검증

- 전체 회귀 1,192개 통과, 기존 pykrx deprecation 경고 1개. 문법 검사 및 diff 공백 검사 통과.
- 마감 시간 분기, 계좌 연결률, 날짜가 다른 시나리오 비교 보류, 5bp 경계, 뉴스 세션, 다음 발표일, 키 비노출 검증.
- 새 Streamlit 실행에서 국내 36/미국 52 대표 종목과 ETF 전환을 테스트했다. 브라우저에서도 합성 가격으로 대표 종목 기본 선택과 개별주 타일을 확인했다. 실시간 제공처/Cloud 배포 검증이 아니다.
- 예시 재생성: `py -3.11 -X utf8 scripts/generate_close_report_sample.py`.
- 산출물: `docs/samples/market_report_20261019_close.md`. 계좌 비중 및 한국 반도체 ETF +0.10%는 테스트 자료이며 실제 계좌/실시간 시황으로 사용하면 안 된다.

수정은 로컬 작업물이다. 커밋/푸시/Cloud 배포는 하지 않았다. 배포 후 저장된 이전 Markdown을 읽는 대신 시황을 다시 생성해야 한다.
