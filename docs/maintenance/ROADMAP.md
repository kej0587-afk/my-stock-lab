Updated: 2026-11-24 KST. 현재 실행할 한 건은 루트 `HANDOFF.md`의 **Next Task Only**가 정한다.
이 문서는 우선순위와 완료 기준이다. 여러 단계를 동시에 수정하라는 지시가 아니다.

## 사용자가 얻어야 하는 결과

**시장 변화 이해 → 강한 업종과 대안 탐색 → 기업/ETF 근거 확인 → 타점 확인 → 계좌에 맞는지 검토 → 사용자가 결정**.
시황은 사건·근거·보유 영향·다음 확인을 설명하고, 정밀관측소는 선택한 종목을 더 깊이 검토한다.
연결 수나 지표 수를 늘리는 것 자체를 완료 기준으로 삼지 않는다.

| 역할 | 답해야 하는 질문 | 중복 방지 원칙 |
| --- | --- | --- |
| 후보 품질 | 기업/상품의 강점·약점과 자료 신뢰도는? | 후보 등급을 매수 허가로 해석하지 않는다 |
| 기술적 타점 | 가격 위치·추세·패턴·손익비는? | 재무 점수를 다시 합산하지 않는다 |
| 실행·계좌 제한 | 현재 시장·비중·현금 조건에서 검토 가능한가? | 최종 제한을 다른 화면의 후보 문구가 해제하지 않는다 |
| 포트폴리오 | 중복 노출·레버리지·현금·손익은? | 배당·환산 노출·미실현손익을 중복 계산하지 않는다 |
| 시황·기업 해석 | 무엇이 바뀌었고 왜 중요하며 무엇을 확인할까? | 위 근거를 읽어 설명하며 별도 판정 엔진을 만들지 않는다 |

| 순서 | 범위 | 현재 확인된 상태 | 이 단계를 끝내는 기준 |

| 1. 데이터 기준 | 종목, 가격 종류, 거래일, 종가/장중, 출처, 공시 기간 | 가격 근거 전달은 운영 검증됨. Naver polling의 종목별 시각은 공급 응답에 없음. 두 고정 입력의 장중/완료봉 사용 대조 완료; 시황 달력 정합화·고정 입력 보존 검증. 일간 등락 실제 비교 날짜·장중 여부 설명 연결 | 같은 고정 입력의 실제 사용 행·기간·가격을 추적할 수 있고, 누락과 다른 목적의 계산을 구분한다 |
| 2. 화면 간 일관성 | 전광판·오늘점검·정밀관측소·돈흐름·포트폴리오 | 공통 판단 요약과 진입 계획 연결은 구현·대조됨. 모든 시장 상태·상품을 검증했다는 뜻은 아님 | 보유/미보유, 주식/ETF/레버리지의 대표 고정 사례에서 등급·타점·게이트가 같은 근거를 사용하며 차이는 설명 가능하다 |
| 3. 해석의 완성도 | 시장·주도업종·실적 촉매·기업 현금흐름·보유 영향·다음 일정 | 공식자료 및 기업 심층분석 기반 존재. 최신 실적/예상/수동 자료 구분과 여러 날짜의 실제 리포트 점검은 계속 필요 | 요약에서 핵심 변화·관련 보유·다음 확인을 읽을 수 있고, 상세에서 원자료·날짜·반대 근거를 추적한다. 확인되지 않은 인과는 사실로 쓰지 않는다 |
| 4. 실제 병목 개선 | 시세, 지표, 공시·뉴스, 리포트 작성, 잠금·대기, UI 재실행 | 요청 재사용·병렬화·지표 최적화 다수 완료. 최근 운영 95종목 106.065초는 일반 새로고침 한 건이며 완전 냉각 기준 아님 | 같은 종목·입력·캐시 조건에서 전후 측정하고 원격 요청/캐시 미스/벽시간을 분리한다. 결과 동일성을 확인한 개선만 채택한다 |
| 5. 큰 함수 분리 | 남은 UI 조합·판정·보고서 함수 | 이미 여러 순수 함수와 렌더러 분리됨. 전면 리팩토링 완료는 아님 | 한 책임씩 옮기고 기존 계약·대표 입력 전체 결과가 동일하다. 오류 처리·호출 순서·상태 변경도 유지한다 |

단계 1의 공급사 미제공 항목 하나 때문에 모든 단계를 무기한 막지 않는다.
**실제 결함은 수정하고, 외부 제약은 근거와 영향 범위를 적어 관리한다.**
뒤 단계 점검에서 수치 오류가 발견되면 관련 데이터 경로만 먼저 고친다.
속도 목표(예: 1분)는 비교 가능한 실측으로 가능성을 판단하며 기능·TTL 축소로 맞추지 않는다.

379810·GOOGL 고정 입력에서 저장된 현재가·RSI·ATR·등락·R/R과 확인축의 날짜·가격을 재현했다.
GOOGL 판정은 장중 봉, 확인축과 시황 종가는 완료봉을 쓰며 목적이 다르다.
특수장 마감 전인데 일부 시황 함수가 마감으로 보던 달력 불일치를 수정했다.
시황 상태·완료봉 필터는 같은 거래소 달력을 쓰고, 화면별 완료 대기시간은 유지한다.
휴장·단축장·서머타임 경계와 보존 입력 동등성을 검증했다. [수정 기록](20261121_report_exchange_calendar.md).
기존 점수·판정은 변경하지 않았다. [감사 기록](20261121_partial_daily_bar_audit.md).

Naver polling과 모바일 basic을 삼성전자·SK하이닉스·국내 ETF에 대해 교대 순서로 두 차례 조회했다.
장종료 가격은 같았지만, 요청 수는 **일괄 1회 대 개별 3회**였다.
SK하이닉스의 선택된 원가격과 별도 NXT 가격은 달랐다. 다른 가격의 시각을 붙일 수 없다.
현재 두 경로 비교만으로 안전하고 비용이 늘지 않는 일괄 교체를 뒷받침하지 못하므로 운영 경로를 유지한다.
장중 동등성은 아직 실측하지 않았다. [비교 기록](20261121_naver_source_comparison.md).
