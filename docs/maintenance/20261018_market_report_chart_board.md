# 2026-10-18 Market Report, Chart, Market Board

## Scope

Four roles were used: data/logic audit, official-source research and economic
collector, chart/market UI implementation, and independent review/tests.
Existing trade decision labels, thresholds, candidate grades and execution
gates were not rewritten. Report-only macro explanations are explicitly
separate from the execution gate.

## Delivered

- `report_evidence.py`: deterministic front matter, KR/US closing-session dates,
  latest official observations, source-linked news, explicit unknown causes,
  cross-market gap risk, holding reasons, safe leverage estimates and changes.
- `economic_releases.py`: bounded official BLS collection; optional Census/FRED
  APIs, unit/basis-aware event consensus merge, successful-response caching.
- `report_context.py`: prices and official releases collected only on report
  generation. The app passes original dated calendar events, not display-only
  MM/DD strings. Existing account-scoped snapshots now retain one earlier date.
- `today_news.py`: source allowlist before per-query quota, ISO timestamps and
  publisher domains. Deduplication groups events; ETH has crypto priority.
- `chart_enrichment.py`: attributed MPL volume classification, volume-conserving
  estimated profile with POC/value area, pure financial snapshot helpers.
- `chart_review.py` and thin `app.py` integration: separate volume axis, smaller
  profile overlays, profile histogram and saved financial ratios. Saved percent
  points are explicitly normalized, including numeric strings.
- `market_board.py`: KR/US/crypto, 1D/1W/1M/3M, closed-bar dates, bounded fetch,
  symmetric colors, sector drilldown, symbol history and return sorting.
  It is a representative ETF basket, not a full-index constituent heatmap.
  Tile area is equal, not invented market capitalization.

## Deliberate Limits

- No live LLM was added. Numbers and interpretations remain deterministic.
- Without Census/FRED credentials those series remain unavailable. Keyless
  FRED CSV fallback was checked but returned HTTP 404, so was not added.
- KR CPI/exports need verified series mapping and ECOS/KOSIS access. They are
  explicitly unavailable rather than supplied by guessed news numbers.
- No inferred consensus, release date, or intraday reaction. Event actual vs
  forecast is compared only with matching units/basis and identifiable period.
- No verified intraday event-window market-reaction feed was added. Daily
  close moves are not advertised as the reaction to an economic release.
- Sources can yield fewer than five qualifying distinct events. Missing slots
  are stated rather than padded with duplicate or promotional news.
- News causal statements require an explicit market, valid timestamp, source
  link, pre-close window and explicit causal wording. Otherwise cause is unknown.
- Cross-listed KR/US daily windows and BTC UTC candles are not multiplied into
  fake same-session leverage returns. ETF proxies are labeled as proxies.
- Volume profile is an OHLCV allocation estimate, not the exchange order book.
- Historical comparison starts from retained account-specific snapshots;
  missing past snapshots cannot be reconstructed retrospectively.
- Sample holdings are illustrative, not a statement about the user's account.
- Cloud deployment and authenticated Cloud rendering were not performed.
