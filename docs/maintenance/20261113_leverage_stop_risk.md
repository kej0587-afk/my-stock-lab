# SOXL 손절 분해와 BITX·나스닥 2배 위험 검토

2026-11-13 연구. 앱 시장방어·투자 기준·비중·주문 변경 없음. 제안만 정리하며 배포하지 않음.

## 핵심 결론

SOXX 손절선까지의 거리와 SOXL 실제 청산 손실은 다르다. 이번 손절 표본에서 큰 손실은 주로
종가 확인 전 움직임과 야간 갭에서 생겼고, 확인 후 다음 시가의 차이는 상대적으로 작았다.
이를 근거로 손절선을 좁히거나 시장방어를 해제하지 않는다. 우선 거래당 손실 예산과 보유 크기를 분리해서 관리할 필요가 있다.

BITX는 비트코인 장기 전망과 별개로 일일 2배·선물·거래시간 제약이 있는 상품이다.
목표비중 미만은 추가매수의 필요조건조차 아닐 수 있으며, 그 자체가 매수 근거는 아니다.
SOXL 60달러 역시 최근 가격대 관찰 후보이지 검증된 반등·매수 조건은 아니다.

## 1. 고정 연구 표본

- 이전 `support_one_r` 63거래 중 `stop_close` 31거래만 분석. 성공 거래를 제외한 손절 사례 분석이지 전략 기대수익 추정이 아님.
- 이전 SOXX/SOXL 수정 1시간 자료와 원장 재사용, 원본 5개 SHA-256 검증. 원장 해시도 결과에 저장.
- SOXX 완료 1시간봉 종가가 고정 손절선 아래면 다음 정규장 봉 Open으로 SOXL 청산하는 기존 연구 규칙 유지.
- 마지막 30분봉은 신호를 만들지 않지만 가격 경로·야간 갭 분석에는 포함.
- 신호 이전 입력만으로 진입한 기존 원장을 사후 분해. 이번에 새 진입·손절 조건을 최적화하지 않음.
- 실제 주문 기록이 아닌 OHLC 체결 가정이다. 호가·주문 지연·실제 슬리피지·거래정지는 재현하지 못함.

## 2. 손절선과 실제 손실

| 항목 | 결과 |
|---|---:|
| 손절 사례 | 31건, 분해 불가 0건 |
| SOXX 진입가→손절선 거리 평균 | 0.391% |
| 위 거리 ×3 단순 참고값 평균 | 1.173% |
| SOXL 비용 반영 손실 평균 | -2.852% |
| SOXL 손실 중앙값 / 최악 | -1.947% / -8.746% |
| SOXX 손절 거리 0.2% 미만 | 10건 |
| 손절 확정이 첫 이탈 관측 봉보다 뒤인 사례 | 10건 |
| 야간 보유 / 음수 야간 갭 | 4건 / 3건 |
| 당일 거래만의 최악 손실 | -6.958% |

31건 모두 비용 포함 손실이 단순 ×3 참고값을 초과했다. 거래별 비율 중앙값은 2.70배이고 최댓값은 17.30배다.
이 비율은 작은 손절 거리 때문에 크게 튈 수 있으며, 미래 손실 보정계수로 사용할 수 없다.
SOXX는 관찰 프록시이고 SOXL의 공식 목표는 NYSE Semiconductor Index의 일일 3배다.
따라서 SOXX 진입가 대비 손절 거리를 3배 한 값을 SOXL의 보장 손절 폭으로 보면 안 된다.

## 3. 갭과 지연 분리

아래는 SOXL 진입가를 공통 분모로 한 가격 변화 기여(%p)다. 각 거래에서 합이 실제 연구 손익과 일치한다.

| 손절 31건의 평균 손익 구성 | 기여 |
|---|---:|
| 봉 내부 Open→Close 변화 | -2.1879%p |
| 정규장 종가→다음 정규장 시가 갭 | -0.4557%p |
| 같은 날 인접 봉 Close→Open 차이 | -0.0040%p |
| 손절 확정 봉 Close→청산 Open 차이 | -0.0100%p |
| 기존 비용 모형 | -0.1945%p |
| 합계 | -2.8521%p |

봉 내부 변화 전부를 '지연 때문에 발생한 손실'이라고 단정하지 않는다. 가격이 정확히 손절선을 통과한 순간의 SOXL 가격은
1시간 OHLC로 알 수 없다. 실제 주문 체결 지연도 관측하지 않았다. 확인 후 시가 차이가 작다는 결과는 이 모형에 한정된다.

별도 시간 분해도 저장했다: 진입→첫 이탈 봉 Open / 해당 봉 Open→Close / 그 Close→확정 봉 Close / 청산 Open.
이 시간 분해와 위 갭 분해는 겹치는 분석이므로 서로 더하면 이중 계상이다.
첫 이탈은 SOXX Low가 손절선 아래인 최초 관측 봉이며, 봉 내부의 정확한 시점·가격은 추정하지 않는다.

### 최악 거래: 2026-07-23 15:30 ET→07-24 10:30 ET

- SOXX 손절 거리 0.169%, 단순 ×3 참고값 0.506%에 비해 SOXL 청산 손실은 **-8.746%**.
- 진입 당일 마지막 30분봉에서 SOXX 저가 이탈을 관측했지만 이 봉은 기존 1시간 신호 대상이 아님.
- 다음 날 09:30~10:30 봉 종가에서 확정 후 청산. 두 관측 봉 시작 시각 간 차이는 18시간이며 실제 최초 통과 후 지연 시간은 알 수 없음.
- SOXL 야간 갭 -3.693%p, 봉 내부 합계 -4.922%p, 확정 후 청산 차이 +0.051%p, 비용 -0.183%p.
- 기존 모형이 그대로 작동해도 손실이 커질 수 있다는 사례이며 코드 버그나 실제 체결 손실을 입증하는 자료는 아님.

다른 손절 사례(2026-07-15 진입)의 야간 갭 기여는 -9.370%p였지만 장중 회복으로 최종 손실은 -5.803%였다.
갭 자체와 최종 손실을 같은 숫자로 취급하지 않아야 한다.

## 6. 제안: 적용하지 않음

1. 비중 상한, 신규 진입 근거, 거래당 허용 손실을 별도 조건으로 둔다. 비중이 남아도 나머지 조건이 없으면 추가매수하지 않는 구조가 필요하다.
2. 기술적 시나리오 폐기선과 계좌 손실 예산을 구분한다. 종가 확인까지 기다리는 규칙만으로 손실 금액을 제한할 수 없다.
3. 크기 산정은 `투입 비중 <= 계좌 허용손실률 / 불리한 ETF 손실 시나리오`를 참고한다. 예를 들어 계좌 0.25%, ETF 손실 시나리오 10%면 2.5%다.
   이는 수치 예시이지 개인 권장 비중이 아니다. 갭이 10%를 넘으면 예산을 초과하며, 최악 이력도 미래 한도가 아니다.
4. 이미 보유한 레버리지들의 동시 하락까지 합산한다. 분할 매수마다 허용손실을 새로 주지 말고 기존 포지션 포함 총예산을 다시 계산한다.
5. BITX는 현재 정보에서 추가매수 보류를 우선 검토한다. 작은 손실을 감당할 수 있다는 것은 강제 손절 이유를 약화시키지만, 추가투입 기대수익을 증명하지 않는다.
   즉시 전량 손절을 단정할 자료도 없다. 장기 BTC 가설을 유지하려면 비레버리지 노출과 전술적 BITX 노출을 구분하는 방향부터 검토한다.
6. SOXL 60달러는 관찰 후보로만 둔다. SOXX 같은 시간봉의 지지 반응, 실패 조건, 비용·불리한 체결 반영 손익비와 기존 시장방어를 함께 통과해야 한다.
7. 다음 하나만 검증한다면 더 세밀한 봉으로 '처음 이탈→종가 확인' 구간과 실제 청산 가능 가격을 확인한다. 자료가 없으면 보류하고 가짜 체결값을 만들지 않는다.
