# 미국 시간외 시세 연결 감사

## 범위
- 시작 main/로컬52d8d79e 일치, 사용자 미커밋 변경 없음. ROADMAP2만 진행.
- SOXL·GOOGL 프리 원응답→선택→cache→정밀관측소/브리핑 경로. 점수·판정·금액·완료 일봉 유지.
- 원응답은 공개 Yahoo quoteResponse 종목 행이며, 인증정보·HTML 전체·계좌목록은 Git 제외.

## 확인 원인과 변경
1. 정밀관측소 시간외 패널이 SOXL/RAM/BITX 등 고정 상품만 허용했다. GOOGL은 원응답에
   프리 체결이 있어도 표시하지 않았다. 선택한 미국 주식/ETF 한 종목에 기존60초/실패15초 캐시를 재사용.
2. 직전 정규장 종가·종가 체결시각과 시간외 가격·종가 대비 등락·체결시각을 함께 표시.
   조회 시각은 cache 내부에 보존하고 체결시각과 구별. 동가 새 체결도 허용.
   20분 초과는 지연 참고값만 표시하고 최상위 실행/시나리오 price로 승격하지 않는다.
3. 시세 검토 JSON에 해당 응답의 허용된 가격/시각 필드와 선택 결과를 함께 저장.
   자동시황 진단에도 같은 관측을 보존. 새 외부 조회를 추가하지 않으며 병렬 cache계측 context만 전달.
   브리핑의 시간외 문장에도 직전 종가 가격·체결시각·Yahoo 출처를 표시.
4. 단축장 시간외는 기존 모두보류 정책이었다. 공식 확인된2026-11-27만13:00~17:00ET 표시용
   세션 등록. 일반장·미확인 단축장·휴장 및 정규종가 인증 규칙은 유지.
   [Nasdaq ETA2026-69](https://www.nasdaqtrader.com/TraderNews.aspx?id=ETA2026-69),
   [NYSE Arca 공지](https://www.nyse.com/trade/hours-calendars).

## 검증 및 제한
- 변경 전 관련117통과. 표시/시세/보고서135통과, 시나리오·판정 연결159통과,
  cache/동일snapshot 연결2통과. 세션/달력 관련200통과(중복있음, 합계로 표시하지 않음).
- 정규장 raw regularMarketTime이 장중이면 완료 종가로 인증하지 않는 기존 정책 유지.
  시각 없는 가격이나 타종목·다른 세션·미래 시세는 현재 시간외가격으로 올리지 않는다.
- 자동 브리핑 시세 조회 범위는 기존 보유+고정업종 유지. 이번 운영 입력의 SOXL/GOOGL은 자동조회
  대상이 아니며 모든 관심종목을 추가 조회하도록 바꾸지 않았다. 두 종목의 renderer 연결은 동일 실제
  원응답 재생과 고정입력 테스트로 검증. 운영 브리핑에 두 종목이 표시됐다고 주장하지 않는다.
- 운영 애프터 실시간 검증은 당일 해당 시간대 전이므로 합성 경계 검증과 구분해야 한다.
- 최종 회귀 gate: prices667통과72.58초, report208통과58.22초, decision1674통과166.89초.
  해당 gate 실패0, 기존 golden 재생성 없음. 리뷰에서VOD.L/SAP.F 미국판별 제외 보완 후 집중108통과6.83초.
- 코드15bb7852 및 접미사보완b1054026 main푸시. 직접 운영Reboot 후 화면 대조 진행.
- 비공개 원응답(cache/extended_quote_before.json)을 수정 renderer에 재생한 결과:
  SOXL35.87/+12.02%/기준종가32.02, GOOGL280.30/+2.64%/기준종가273.10이 정밀·브리핑 모두 일치.

  GOOGL274.89(09:59:35KST). 해당 체결시각으로 재생해 정밀·브리핑 모두 선택됨을 확인.

  이번에는 비교 종가 가격과 체결시각·출처를 명시하여 기준을 구분했다.

  향후 해당 시간대 두 종목 UI/원응답 재확인이 남는다.
