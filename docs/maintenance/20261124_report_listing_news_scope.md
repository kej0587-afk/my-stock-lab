# 다음 일정: '상장사' 정책 기사를 공모 일정으로 잡지 않기(백로그 #17 내용 점검)

작성 2026-11-24 KST.

## 문제

2026-11-24 오후 운영 보고서(PR #10·#11 반영 후 첫 보고서)의 다음 일정 구역에 "증시 급락에…금융당국, 상장사 자사주 1일 취득한도 확대"가
'일정·공모 계획 보도'로 실렸다. 이미 상장된 회사에 대한 자사주 규정 기사인데, 추적 조건 `IPO|기업공개|상장`이 '상장사'의 '상장'에 맞았다.

## 변경

- `report_event_watch.event_watch_lines`: 상장 이벤트 판정에서 '상장사·상장기업·상장회사·상장주식·상장종목·상장지수'와 '비상장'을 뺀다.
  'IPO', '기업공개', '코스닥 상장 예정' 같은 실제 상장 기사는 그대로 추적한다. 상장폐지 제외도 그대로다.
- 기사 분류 표시만 바뀐다. 일정 확정, 수치, 판정은 바꾸지 않는다.
