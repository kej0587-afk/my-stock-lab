# 미국 돈흐름 기준일 혼재 원인 점검

## 범위와 확인된 원인

- 시작 main `8181e090`, 첨부 HANDOFF와 동일, 미커밋 변경 없음.
- 로컬 설치 yfinance 0.2.66, 현재 운영과 같은 `period=1y/interval=1d/auto_adjust=False` 요청을
  SOXX·XLK·MSFT에 재현했다. 원래 반환 프레임에도 11/27 High/Low/Volume은 있지만 Close는 NaN이다.
- Yahoo v8 원응답(HTTP200)도 SOXX·MSFT의 11/27 `close:null`을 확인했다. SOXX 5d/2y,
  MSFT 1mo에서도 동일했다. 메타 regularMarketPrice는 있지만 완료 일봉 종가로 대체하지 않았다.
- 돈흐름 추출기는 기존부터 필수 Close/High/Low 누락 행을 제외한다. 마지막 정상봉11/25를 사용한 것은
  해당 고정 입력에서 정상 동작이며, 완료봉 달력 처리 또는 오래된 계산 캐시가 새 봉을 삭제한 것이 아니다.
- 대조 2종목의 현재 재수집도 마지막 정상봉11/25/수신11/27 Close누락이었다. 이전 운영의11/27 값 및
  11/19 값이 당시 어떤 원응답/폴백에서 왔는지는 원본이 없어 이번 새 응답만으로 단정하지 않는다.
  공급처가 왜 null을 제공하는지, 언제 복구되는지도 미확인이다.

## 수정 내용

- 과거봉을 사용하는 이유가 사라지던 진단 누락을 보완했다. 추출된 프레임의 별도 메타정보로
  `원자료최근봉 / 원자료누락항목 / 원자료사유`를 전달하고, 유효 점수가 있는 행도
  `최근봉 불완전 · 이전 정상봉`으로 원자료 진단에 표시한다.
- 시장별 기준일 표에는 최근봉 필수값 누락 건수를 추가하고, Today 요약에도 해당 사유를 표시한다.
- 시장 간 달력 합집합의 전부 빈 행은 수신 봉으로 보지 않는다. 거래량만 누락이면 기존처럼 가격봉을
  유지하고 거래량을 채우지 않는다. 날짜·종가 임의 보정/추가 외부 조회/TTL·실패 재시도 변경 없음.
- 원자료 날짜가 섞이면 기존 오늘 한 줄 비교 제외를 유지한다. 점수·투자게이트·시장방어·월적립·L3·금액 불변.

## 검증

- 수정 전 관련159통과5.03초 → 새 회귀 포함163통과6.03초.
- 저장한 실제 공급 프레임3종목으로 이전 추출과 새 추출의 모든 기존 지표/점수/상태/기준일 값 동일 확인.
  달라진 것은 원자료 누락 진단 필드뿐이다. 원응답은 cache에 보존하며 Git에 올리지 않는다.
- 가격 범위 회귀와 운영 배포 결과는 HANDOFF 최상단에 기록한다. 이번 재수집은 로컬 확인이며,
  과거 운영 응답 자체를 복원한 것 또는 공급처의 최신 종가가 복구된 것으로 표현하지 않는다.
