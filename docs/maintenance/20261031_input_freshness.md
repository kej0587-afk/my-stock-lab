# 가격·돈흐름·재무 기준일

## 확인한 원인

- Yahoo 다종목 프레임은 시장별 거래일의 합집합을 가진다. 종목 추출 후
  OHLCV 전체를 forward-fill하면 휴장일에 가짜 가격·거래량이 생긴다.
  일간 등락이 0이 되거나 5/21/63봉 기간이 실제 거래일과 달라질 수 있었다.
- 돈흐름 공통 메트릭에 원 가격 날짜가 없었다. 연결 단계가 날짜 컬럼을
  보존해도 원천에서 만들지 않았으므로 계산시각만으로 최신임을 입증할 수 없었다.
- 정밀관측소 워크플로에는 가격 원자료 기준일·저장 재무 기간이 연결되지 않았다.
  차트의 가격 날짜와 실행 게이트의 근거를 한 표에서 대조하기 어려웠다.
- 한국 지수 `^KS11`, `^KQ11`도 한국 거래소 달력으로 구분해야 한다.

## 변경

| 대상 | 적용 |
| --- | --- |
| 돈흐름 원자료 | 전일 값으로 빈 OHLCV를 채우지 않음. 불완전 가격 행 제외, 거래량 NaN 보존 |
| 원천 날짜 | 실제 마지막 가격 봉과 마지막 유효 거래량 봉 날짜를 별도로 전달 |
| 가격 신선도 | 한국 XKRX·미국 XNYS의 실제 마지막 확정 종가일과 비교. 장중 진행 세션은 구분 |
| 휴장·단축장 | 기존 exchange_calendars 일정 캐시 재사용. 단순 평일 계산으로 대체하지 않음 |
| 암호화폐 | 지원 BTC/ETH USD의 UTC 일봉 마감·진행 봉 구분 |
| 기타 해외 거래소 | 달력 미연결로 명시. 미국 달력을 대신 적용하지 않음 |
| 가격 검증 실패 | 새 기준일 계약이 있는 결과의 지연·미래·불명확 날짜는 기존 데이터확인 게이트 사용 |
| 돈흐름 제약 | 실제 대기/약세 제약에 쓰는 자료의 날짜·거래량이 어긋나면 데이터확인. 잘못된 자료를 지워 매수로 승격하지 않음 |
| 선택적 긍정 맥락 | 날짜 불일치 자료는 참고 전용·실행근거 제외 표시. 긍정 돈흐름은 원래도 실행 허가를 부여하는 조건이 아님 |
| 저장 재무 | 보고기간·계산시각·최신 발표 미확인 상태를 따로 표시. 6시간 경과를 실적 악화나 강제 만료로 사용하지 않음 |
| 화면·검토 ZIP | 가격/돈흐름/재무 3행 비교 표를 같은 자료로 출력. 원 기준일과 계산시각을 바꿔 쓰지 않음 |

후보 점수·재무 등급·매매 임계값·기존 판정문구는 바꾸지 않았다.
가짜 봉을 제거한 데이터에서는 수익률·돈흐름 점수·후보 순위가 달라질 수 있다.
동일한 정상 원자료의 계산식을 바꾸는 수정과는 구분한다.

## 캐시·성능

- 돈흐름 집계 캐시와 압축 후보의 계산 버전을 올렸다. 날짜가 없는 과거 테마
  캐시를 새 ETF 스냅샷에 무조건 재사용하지 않는다.
- 오늘점검 파생 계산 버전도 갱신한다. 계좌·수동 점수·관심종목·원 이력은 삭제하지 않는다.
- 오래된 레이더 원본을 조회시각으로 다시 찍지 않는다. 실제 갱신 전에는 기준일 미확인이다.
- 네트워크 시세/뉴스/공시 조회를 추가하지 않는다. 거래소 일정은 로컬 라이브러리다.
- 별도 프로세스의 100행 날짜 점검: 최초 2.751초, 일정 캐시 이후 0.005초.
  전체 오늘점검 시간 측정이나 개선율이 아니며 환경에 따라 다를 수 있다.

## 검증 범위

합성 다시장 프레임의 가짜 주말 봉·불완전 OHLC·누락 거래량,
휴일·서머타임·단축장·장중 경계, 한국 지수의 시장 분류,
오래된 가격/돈흐름과 최신 계산시각의 구분, 원본 불변과 재적용,
저장 전 워크플로 검증 및 화면/ZIP 연결을 검사한다.

보고기간이 오래됐다는 사실만으로 더 최신 공시가 나왔음을 추정하지 않는다.
공시 공급자의 최신 반영 여부나 전 종목 컨센서스의 정확성을 이번 날짜 검증으로
입증한 것은 아니다. 레거시 입력 중 원 날짜가 전혀 없는 경로는 미검증으로
구분하며, 실제 앱의 신규 계산에는 기준일 계약을 연결했다.

## 검증 기록

- 관련 검사 220개 통과(27.68초), 전체 회귀 4,137개 통과,
  1개 건너뜀, 하위 테스트 18개 통과(187.93초).
- 한국 지수 달력 분류를 독립 리뷰에서 재현·수정했다.
- 해외 미연결 지수를 미국으로 추정하지 않도록 보강한 뒤 관련 검사
  148개도 통과했다(16.64초).
- 긍정 돈흐름은 원래 실행 승인 조건이 아니므로 날짜 불일치는 실행근거 제외로
  표시한다. 이 정책과 실제 gate 사용 경로를 독립 리뷰에서 다시 확인했다.
