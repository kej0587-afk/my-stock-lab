# 2026-10-14 집중 수정

집에서 반영한 최신 코드를 유지하고 아래 경로만 수정했다.

- `decision_workflow`: 통합 가드의 신규매수 중단과 지역 위험/비상을 일반 종목에도 전달한다. 기존 후보점수/손익비 조건은 바꾸지 않는다. 지역 비상만 있으면 해당 시장에만 적용한다.
- `market_basis`: 지수·ETF의 일봉 공통 날짜를 시장별로 정렬한다. 시작/종료일, 최근수신봉과 정렬 여부를 표시하고 `11_market_benchmarks.csv`로 내보낸다. 이는 동시 장중 시세나 지연 없는 가격의 보장이 아니다. 미국과 한국은 서로 정렬하지 않는다.
- `earnings_calendar`: Yahoo 조회 제한 후 실적일 API 요청을 180초 쉬며 다른 종목도 같은 제한을 공유한다. 실패 반환은 24시간 대신 60초 캐시한다. 미조회는 안전 표시를 하지 않는다. Yahoo의 다른 API 전체 제한을 해결한 것은 아니다.
- 키움 시장 관찰: 모의환경 성공 응답을 일괄 폐기하지 않는다. 환경을 표시하고 실제 오류 상태를 보존한다. 사용자 키/계좌/주문에는 접근하지 않았다.
- 감사표: 목표비중 입력 변경과 계산 당시 값을 구분해 재계산 항목을 추가한다. 이전 신호에 새 비중만 덮어씌우지 않는다. 현재비중의 단순 시세 변동을 입력 오류라고 단정하지 않는다.

검증은 공급자 응답 대체 테스트와 실제 앱 함수 경계 테스트다. Cloud 배포/사용자 키 인증 성공이나 투자 성과를 검증한 것은 아니다.

남은 별도 범위: 뉴스 공급/오분류, 시황·섹터 원천의 1D 갱신 계약, 하드차단 용어 전체 통일, 상태 전환 완충. 이번 수정으로 전체 리포트가 검증됐다고 보지 않는다.
