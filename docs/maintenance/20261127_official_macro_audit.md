## 계측 의미

- `official_http.*`: 개별 매크로/일정/정책/전망 HTTP 호출 경계 및 상태. requests 내부 자동 redirect/retry는 별도 미계측.
  기존 `report_http`/`bulletin_http`와 같은 요청을 관측하므로 합산 금지.
- `earnings_collection.*.http`: 기존 Session.send 경계의 실제 송신(SEC admission 뒤),
  `.get_calls`/`earnings_discovery.http.*.attempt`는 상위 조회 경계이므로 중복 합산 금지.
- cache lookup/hit/miss, 잠금 획득 대기, provider/본문, 탐색·변환·저장, 시간한도 미조회 별도.
- `first_started_seconds`/`last_finished_seconds`는 전체 생성 시작 후 해당 함수 첫 시작/마지막 종료.
  병렬 worker 대기 합계는 사용자 벽시간이 아님. `active_wall_seconds`도 서로 겹칠 수 있음.
- 진단에 원 URL·API key·계좌 목록을 추가하지 않음. coverage는 건수와 상태만 저장.
