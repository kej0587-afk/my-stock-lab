# 돈흐름 OHLC 외부 조회·대기 감사

## 결론과 변경

시작 clean `6bf43e58`, 최신 main과 동일. 점수·판정·필터·기간·병렬 수·TTL·timeout을 유지했다.
이번 변경은 누락된 진단 보강이다. 같은 batch 재조회나 국내 슬롯 병목은 관측되지 않아
캐시를 늘리거나 락을 제거하지 않았다. `YAHOO_HISTORY_LOCK`은 다른 조회와의 안전한 직렬화를 유지한다.

- OHLC 국내 캐시 접근 / 배치에서 메모리 추출 / 폴백 분리.
- 해외 배치 cache lookup/miss/reuse와 공급처 호출, 같은 배치·종목의 반복 집계.
- 배치 잠금·provider 호출·국내 슬롯 대기 분리. FDR 성공/실패 TTL900/15초 그대로.
- 실행당 key별 최대4096개까지 집계(초과 별도 count). 종목/요청키는 report에 포함하지 않는다.
- **yfinance provider_call은 yf.download 호출 수이며 내부 HTTP 수가 아니다.** 내부의 쿠키·재시도·
  개별 시세 요청 수는 미계측이다. 직접 Naver/해외 fallback HTTP와 구분한다.
