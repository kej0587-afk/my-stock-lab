# C-4 하락 차트 패턴 정책 (2026-11-25, 사용자 결정 A″+)

## 결정
- 상승 패턴의 기존 판정 경로는 유지한다("✅패턴유효: 정밀확인", "돌파대기", "눌림대기").
- 하락 패턴은 기본적으로 기술검토 표시용이다. 다음 단계는 판정분류와 실행게이트를 바꾸지 않는다.
  - 단순 형태 관찰
  - 목선·지지선 종가 이탈
  - 거래량 동반 이탈
- **목선·지지선 종가 이탈 + 주요 가격 구조 훼손**이 동시에 확인될 때만 기존 "🛑하락패턴 유효" 실행 보류를 유지한다.
  - 문구, risk 버킷, 게이트 "하락/저항 패턴 확인 필요" 또는 방어우선은 기존과 같다.
- 구조 훼손의 정의는 비교에서 검증한 조건 그대로이고, 새 임계값은 없다.
  - 엔진 `structure_risk` 표시, 또는
  - 현재가 < MA50 이면서 외부구조 Bearish
- 거래량 동반 기준은 이탈일 거래량이 직전 20봉 평균의 1.5배 이상인 경우다(기술검토 그림자의 기존 1.5배). 단계 표시에만 쓴다.
- 패턴 무효화(무효선 회복)는 표시만 한다. 다른 안전장치는 계속 적용된다.
- 패턴에 의한 실행 보류는 자동 매도나 손절과 연결하지 않는다(원래도 연결 없음).
- 이 조건은 C-4 패턴 정책에 한정한다. C-5 기술검토층에는 실행 차단 권한이 없다.

## 구현
- `stock_lab_core/chart_patterns.py`
  - `classify_bearish_pattern_stage`, `bearish_structure_damaged`
  - `summarize_chart_pattern_for_dashboard`의 하락 분기: 구조 훼손 동반만 "🛑하락패턴 유효"(risk). 나머지는 "📉하락형태 …(참고)"이고 버킷이 없다.
  - `build_chart_pattern_timing_note` 문구
  - `detect_chart_pattern_candidates`가 하락 현재유효 패턴에 `breakdown_volume_ratio`를 붙인다(판정일까지의 봉만 사용).
  - `detect_recent_invalidated_patterns`(표시용)
- 게이트, 엔진, 상위시간대 가드, 시장방어, 매크로, 데이터, R/R, 비중 코드는 바꾸지 않았다.

## 검증
- 사전 추적
  - §2.4의 "이탈 + 구조훼손" 21건은 모두 우량주 회복 정찰(QUALITY_RECOVERY_SCOUT/CANDIDATE, HOLDING_ 계열)이었다.
  - 회복 정찰은 엔진 우선순위상 구조훼손 하드가드(STRUCTURE_DAMAGE_*)보다 먼저 정해진다. 그래서 하락 패턴이 유일한 브레이크였다. 이 단계의 보류를 유지한 이유다.
  - 추적 결과: `/mnt/project-files/reports/c45_study/trace21.csv`
- 상승 '정밀확인' 경로
