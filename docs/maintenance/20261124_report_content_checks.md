# 자동점검에 내용 점검 추가(백로그 #17)

작성 2026-11-24 KST.

## 배경

자동점검 표는 연결·기준일만 확인했다(대표지수 기준일, 계좌 입력, 테마 본문, 개인 수급 이력, 한국은행 일정).
오늘 운영 보고서에서 사람이 찾아낸 결함(같은 기사 갱신판 반복, 다른 달 설문처럼 읽히는 예상치 설명) 같은 유형을
다음부터 보고서가 스스로 표시하도록 기계적으로 확인할 수 있는 항목을 추가했다.

## 추가 항목(`report_digest.content_checks`)

| 항목 | 실패 조건 | 미확인 조건 |
| --- | --- | --- |
| 시황 본문 기사 중복 | 한국·미국 시황의 **같은 표** 안에서 같은 원문 링크, 또는 같은 문장(30자 이상, 링크·시각 제외)이 두 행 이상 | 본문 원문 링크 없음 |
| 컨센서스 대상월 | 예상치의 대상월(`forecast_period`)이 행의 관측월과 다름 | 예상치 없음, 또는 대상월 표기 없는 예상치가 있음 |
| 관측실·현지 지수 기준일 | 생성일(KST)보다 뒤 날짜의 관측값 | 표시할 관측값 없음 |

- 다른 표가 같은 원문을 근거로 다시 인용하는 것(예: 업종 표가 뉴스 행의 기사를 근거로 씀, 안전장치 표와 뉴스 행)은 중복이 아니다.
  14:57 KST 운영 보고서의 링크 반복 6건을 대조해 이 경우를 제외하도록 정했다.
- 기사 주장이나 예상치의 품질을 판정하지 않는다. 표 문구에도 그렇게 적었다.
- 요약 문구는 "자동점검(연결·구조·내용 일부)"로 바꿨다.
- 점수·판정·수치는 바꾸지 않았다.

## 함께 고친 반복 기사

14:57 KST 운영 보고서 미국 시황에서 연합뉴스 두 기사(AKR20261123176151072, AKR20261123176152072)가 제목은 다르지만
같은 검증 본문 문장("AI 투자 관련 보도: AI 관련 기업들의 주가가 지나치게 높아졌다는 거품 논란…")으로 두 행에 실렸다.
`report_brief.build_news_brief`에서 같은 시장·대상 안에 검증 본문 문장 묶음이 같은 기사는 한 번만 싣는다.
본문 문장이 다른 기사, 본문이 없는 기사는 기존 규칙(링크·제목 키) 그대로다.
