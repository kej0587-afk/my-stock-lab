# SOXL 단기 관찰 시안

## 재사용 범위

| 기존 기능 | 재사용 | 제외/분리 |
|---|---|---|
| 스윙 레이더 | 후보 탐색·기존 저장 판정 | 신규 단타 허용으로 변환 안 함 |
| SOXX 1시간 지지 관찰 | 상태·완료봉 시각·확인 조건 | SOX/SMH/QQQ는 참고, 점수 중복 가산 없음 |
| SOXL 가격 계획 | 같은 진입가·자체 손절선·1R | 3배 단순 환산·새 목표가 생성 없음 |
| 거래량·패턴·매물대 | 통합 분석 차트에서 선택 봉으로 확인 | 거래량 돌파 진입 규칙은 미검증 |
| 가격 위치·시나리오 | 현재 계획의 가격·무효 조건 | 일봉 A/B/C와 단기 1시간 계획 혼합 안 함 |
| 손실예산 | 기존 수량 시나리오 | 계좌 비중 저장·자동 주문 없음 |

관찰 요약은 현재 상태/진입가 근거/확인/손절/익절/최대보유/보류 사유 7행이다.
유효한 가격 쌍이 없으면 그 이유를 남기고 임의로 손절가를 낮추지 않는다.
최대 보유는 아직 운영 정책 미설정이며 연구별 기간을 구분한다.

## 유형 분리

- 급락 반등: 일봉 -20% 연구 후보. 5분 대조 통과 0건, 현재 승률 없음.
- 추세 눌림: 기존 SOXX 관찰 + SOXL 자체 가격 계획. 추세가 실제 성립해야 하며
  화면 제목만으로 상승 추세를 선언하지 않는다.
- 거래량 돌파: 기존 표시 데이터 재사용 후보일 뿐 규칙 미고정·미검증.

## 확대 순서 (운영 적용 전 사용자 결정)

1. 미국 일반 ETF: 세션·분할·분배금·경매 포함 가격 대조, 거래비용과 유동성 검증.
2. 미국 개별주: 실적/거래정지/갭·상폐 표본·생존편향 추가.
3. 국내 일반 ETF·개별주: 정규장/단일가·가격제한폭·거래세·호가단위·정지일 구분.
4. 레버리지 ETF: 일일 리셋·기초지수 차이·파생비용·경로 의존·장외 괴리 검증.
5. 각 모집단 독립 기간 모의기록과 위험예산 검토 후 사용자가 운영 적용 여부 결정.

한 종목의 과거 승률을 다른 종목에 복사하지 않는다. 이번은 SOXL 읽기 전용 시안이다.

## 검증

- 차트/가격계획/요약 집중 테스트 34개 통과.
- 기존 decision gate 1,669개 통과, 174.095초. 임계값/가격 계산 함수 변경 없음.
- 새 기능은 기존 plan/readiness/context를 읽기만 한다. 수동 진입가 복원 테스트 유지.
- 모바일 수정은 metric을 직접 담는 마지막 행에만 2열 CSS를 적용한다.
- 운영 화면 확인은 배포 후 이어서 기록한다.
- [DART cold 계측](20261127_dart_cold_audit.md)은 별도 측정이며 속도 개선 주장 아님.
