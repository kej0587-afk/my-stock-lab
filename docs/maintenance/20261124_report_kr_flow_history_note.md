# 한국 시황: 수급 이력 표의 기준일·부호 설명(백로그 #14)

작성 2026-11-24 KST · 근거: 보고서 (61) 130~151행.

## 문제

독자용 보고서는 수급 표를 복사할 때 원래 표 아래 설명을 버리고, 모든 표에 "억원(잠정)"을 붙였다. 그래서
- 오늘(11-24) 잠정 표에서는 외국인이 순매수인데, 바로 아래 이력 표(11-23까지)에는 "외국인 순매도 7거래일"이 나와 같은 시점처럼 읽혔다.
- "개인 순매도 1거래일 · 5거래일 누적 +9,429"처럼 연속 방향과 누적 부호가 다른 행을 설명 없이 보여 줬다.
- Npay 이력은 완료 거래일만 쓰는데도 "잠정"으로 표시됐다.

## 변경

- `report_reading._kr_flow_table_lines`(기존 복사 블록을 함수로 분리, 동작 동일 + 설명 추가):
  - Npay 이력 표(헤더 "누적")는 "억원(완료 거래일)"로 표시하고 "기준일(…) 마감까지의 완료 거래일 기준"을 적는다.
  - 저장 스냅샷 이력 표(헤더 "합계")는 원래 설명대로 "기준일 장중 수치가 포함될 수 있음"을 적고 "잠정"을 유지한다.
  - 위 잠정 표의 날짜가 이력 기준일보다 뒤면 "위 YYYY-MM-DD 잠정 수급은 포함하지 않습니다"를 붙인다.
  - 연속 일수와 누적 합계의 부호가 다를 수 있다는 한 줄을 붙인다.
- 수치·부호·연속일 계산은 바꾸지 않았다.
