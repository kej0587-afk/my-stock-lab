# C-6/C-11 4단계: 코어 ETF 월적립 게이트 비교 리플레이 (2026-11-26)

사용자 결정 9항. 코드·규칙 변경 없음(분석만). D 예외는 사용자 검토 전까지 비활성입니다.

## 방법
- 대상: QQQ, SPY, SOXX, XLK, 069500.KS, 091160.KS (모두 코어 ETF). 2008-01 ~ 2026-11, 월 1,306개.
- 매월 첫 거래일에 계획(= 월 예산 1 × 엔진 원코드 배율)을 정하고, 그 달 0·5·10·15번째 거래일에 게이트를 확인해
  처음 허용된 날 종가로 집행. 끝까지 막히면 현금으로 남김(재배분 없음, 현금 이자 0).
- 변형: A 현재(항상 집행) / B C1(실행가능만) / C C2(실행가능 또는 타이밍 대기만) /
  D C2 + 상위 시간대 추세훼손 예외.
- D 구현: 게이트 입력에서 '상위 시간대 경고' 표시 하나만 지우고 게이트를 처음부터 다시 계산합니다.
  최우선 사유를 건너뛰는 방식이 아니라서 데이터, 비중, 시장방어, 하드차단, 매크로 미확인, 방어 문구, 레버리지 조건부는 그대로 막힙니다.
- 시장 가드: 벤치마크 10개(^KS11, ^KQ11, 069500.KS, 229200.KS, ^GSPC, ^IXIC, ^DJI, SPY, QQQ, IWM)의
  그 날짜까지 종가로 국장·미장 모드와 비상 규칙을 재현. 돈흐름·매크로·이벤트 점수는 과거값이 없어 빠졌습니다
  (운영 가드가 이보다 엄격할 수 있음).
- 데모 보유표를 비우고 명시 비중(현재 5 / 목표 15)을 썼습니다. 평단은 A 경로 평단을 모든 변형에 공통으로 써서
  판정 입력은 같고 집행 규칙만 다릅니다.
- 매크로: base(리스크 1.0, 패널티 0)와 stress(4.6, 2.0) 두 가정. 과거 매크로 재현은 불가능합니다.

## D가 다른 차단을 유지하는지
- 추세훼손 표시가 있는 확인 시점 3,464건 중 C 집행 0건, D 집행 2,786건.
- D에서도 막힌 678건: 시장방어(신규매수 중단) 442건, 시장/가격/추세 방어 문구 236건.
- PANIC_CASH_DEPLOY, PANIC_FINAL_DEPLOY, MACRO_STORM_HOLDING_CAUTION은 D에서도 0건 집행.
- 시장 가드 '위험' 시점(692건)은 B·C·D 모두 0%.

## 해석
- C는 낙폭 150% / 폭락 200% 국면에서 배율이 커지는 바로 그때 대부분 막힙니다(추세훼손 때문). D는 이 구간을 엽니다.
- D는 CORE_STORM_DCA도 대부분 엽니다. 결정 2에서 CORE_STORM_DCA·PANIC_*은 C-8/C-9 소관이고
  퍼펙트스톰은 그대로 둔다고 하셨으므로, D 적용 범위에서 CORE_STORM_DCA를 빼는 안을 권장합니다.
  그러면 stress 가정의 D는 C와 같아집니다(69.4%).
- 2008~2026은 대체로 상승장이라 '집행할수록 평가액이 큰' 결과가 나옵니다. 하락장이 길었던 시장에서는
  다를 수 있습니다.
