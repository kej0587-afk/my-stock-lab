# 재무·모멘텀 성적표와 ETF 구성종목 검토 연결

## 적용 범위

성적표를 기존 점수에 더하면 ROE·이익률·성장·RS·추세 등이 기존 재무/기술 판정과 중복될 수 있다. 이번에는 기존 매매 등급·문구·임계값을 유지하고 성적표를 최종 체크의 설명과 검토 ZIP에 연결했다. 새 매매 가중치의 성과가 검증됐다는 뜻은 아니다.

| 항목 | 반영 |
| --- | --- |
| 성적표 | 6개 축의 점수, 자료 수, 부분자료/미수집 구분 |
| 최종 체크 | 자료가 충분한 재무 축의 상대적 높고 낮음, 모멘텀, 현재 게이트를 함께 설명 |
| 중복 방지 | 성적표를 별도 통과표/차단표로 합산하지 않음. 저장 재무 1~4점 유지 |
| ETF 성적표 | 기업재무 해당없음 행을 반복하지 않고 모멘텀만 표시 |
| 검토 ZIP | chart_scorecard.csv, etf_holdings.csv와 JSON 전용 섹션 추가. 기존 판정 CSV에 같은 자료를 다시 넣지 않음 |

자료 충족도는 기업의 좋고 나쁨이 아니다. 서로 다른 축의 원점수 순위는 업종 내 상대평가가 아니며, 자료가 1개뿐인 축은 강약 비교에 사용하지 않는다. 기존 축별 0~100점 산식은 재보정하지 않았다.

## 확인·수정한 오류

- FCF 수익률에서 시가총액과 재무 현금흐름의 통화가 다르거나 한쪽 통화가 없으면 나누지 않는다. GBp(펜스)와 GBP(파운드)도 구분한다.
- 외부 재무 조회 예외, None 응답, data=None이 성적표 전체를 중단하지 않게 하고 저장 자료만 사용했다는 출처를 남긴다.
- 음수 PER를 저평가로 해석하지 않으며, 음수 이익·성장·현금흐름 등을 별도로 표시한다.
- FCF 수익률은 실제 배당·자사주 매입이 아닌 환원 여력 지표임을 구분한다.
- 코드나 자산종류가 검증되지 않은 ETF 항목을 임의 주식 티커로 만들지 않는다.
- 한국 구성종목의 Reuters 코드와 ISIN이 일치하면 .KS/.KQ를 보존한다. 거래소가 불명확한 코드에는 시장 선택 전 검토 버튼을 비활성화한다.

## ETF 연결

정밀관측소와 돈흐름 레이더가 같은 구성종목 조회 경로를 사용한다. 구성종목 조회는 명시적인 버튼으로 실행하고 개별 종목 시세·재무를 일괄 조회하지 않는다. 확인 가능한 구성종목을 선택해 정밀관측소로 이동하며 원래 ETF로 돌아갈 수 있다. 전광판·보유자산에 자동 저장하지 않는다.

| 실조회 대상 | 확인 결과 | 구성 기준일 |
| --- | --- | --- |
| SOXX | 34행, 개별 검토 가능 30행 | 2026-10-29 |
| KODEX 200(069500) | 202행, 개별 검토 가능 201행 | 2026-10-30 |
| CIBR | 47행, 개별 검토 가능 41행 | 2026-10-29 |
| SOXL | 43행, 주식·스왑·현금 구분 | 2026-10-30 |

제공처가 보고한 전체 항목이라도 ETF의 모든 경제적 노출을 뜻하지 않는다. 네이버의 국내 ETF 자료는 설정·환매 바스켓이며 파생상품·현금·외화 구성에 특히 주의해야 한다. 스왑 비중을 기초 주식의 실제 편입 비중이나 일일 레버리지 노출로 바꾸지 않는다. 비중 합을 임의로 100%로 맞추지 않는다.

조회 경로: [iShares SOXX](https://www.ishares.com/us/products/239705/ishares-semiconductor-etf/latest-holdings.csv), [First Trust CIBR](https://www.ftportfolios.com/Retail/Etf/EtfHoldings.aspx?Ticker=CIBR), [Direxion SOXL](https://www.direxion.com/holdings/SOXL.csv), [네이버 ETF 구성자료](https://stock.naver.com/api/domestic/detail/069500/ETFComponent).

QQQ/QQQM의 Invesco 조회는 확인 시 HTTP 406으로 차단됐다. 차단을 우회하거나 QQQ 구성을 QQQM에 임의 복사하지 않았다. 다른 해외 ETF의 Yahoo 상위 10개 경로는 기준일·자산종류 미검증 또는 요청 거부가 있을 수 있다. 이런 ETF는 전체 실시간 구성이 연결됐다고 표시하지 않는다. 이름만 있는 기존 국내 카탈로그는 기준일 미상·검토 불가인 참고 목록으로 한정한다.

기존 SMH/CIBR의 2026-09-29 확인 상위 5개는 최신 조회 결과가 없을 때만 역사적 참고 목록으로 보존했다. 출처·원래 기준일과 '현재 편입·비중이 아님' 경고를 붙이며 최신 조회가 있으면 덮어쓰지 않는다.

## 캐시·시간

- 네트워크 수집 기본 예산 8초, 응답 최대 2MB, 리다이렉트·자동 재시도 없음.
- 성공 캐시 1시간, 실패 캐시 30초. 실패가 이전 성공 자료를 덮어쓰지 않으며 이전 성공 조회는 최대 24시간 동안만 재사용한다.
- 조회시각과 구성 기준일은 다른 필드다. 조회한 오늘 날짜를 구성 기준일로 쓰지 않는다.
- 화면에 보관된 조회가 1시간을 넘으면 새로고침이 필요한 저장 자료임을 표시한다.
- 오늘점검 전 종목 계산 경로에는 새 API 호출을 추가하지 않았다. 이번 작업은 95종목 전체 계산의 성능 재측정이 아니다.

## 검증

로컬 체험 화면에서 QQQM 모멘텀과 MSFT 재무·모멘텀이 최종 체크 설명에 연결되고, 게이트 제한을 해제하지 않는 것을 확인했다.

- 전체 회귀 테스트: **3,958 passed / 12 skipped / 18 subtests passed**, 168.55초.
- 마지막 과거 참고 목록 보존 변경 후 집중 테스트: **173 passed**, 3.67초.
- 운영 배포에서 Git 커밋은 새 버전인데 ZIP이 구버전 1.1이고 성적표 모듈도 이전 구현인 상태를 확인했다. 기존 빌드 진단은 시황 모듈만 추적해 이 불일치를 놓쳤다. 정밀관측소의 성적표·ETF·검토 ZIP 모듈도 로드 당시 해시로 확인하도록 추가했으며, 미등록된 이전 모듈을 최신이라고 표시하지 않는다.
- 이 진단 보완 후 관련 테스트 **248 passed**, 14.01초. 로드한 모듈/새 파일 불일치·미등록·파일 없음·미사용 모듈 제외를 확인했다.
- 진단·체험 화면 이동까지 반영한 전체 회귀 테스트: **3,966 passed / 12 skipped / 18 subtests passed**, 171.17초.
- 로컬 체험 화면에서 TIGER 미국나스닥100(379810.KS) 구성 102개, 비중 합 99.49%, 기준일 2026-10-30을 확인하고 엔비디아(NVDA) 개별 분석 및 ETF 복귀 버튼을 확인했다. 체험 화면에 임시 검토 종목을 추가할 뿐 샘플 관심목록은 저장·변경하지 않는다.
- 사용자 Reboot 후 운영 빌드 `aeaa988d`의 GOOGL 검토 ZIP 1.2 완료 결과를 확인했다. `restart_required=False`, `stale_modules=[]`, 성적표 근거 `linked`, `score_added=0`, `thresholds_changed=False`, 기존 재무 4/4와 실행 제한 유지.
- 구성종목 네트워크 테스트는 주입 응답으로 오프라인 수행했다. 실제 제공처 조회 결과는 위 실조회 표와 구분한다.
- 운영 확인 결과는 배포 후 추가한다. 개인 계좌·비밀값·검토 ZIP 원본은 저장소에 포함하지 않는다.
