# 2026-10-13 화면 안정성과 키움 시장근거

## 확인된 문제와 변경

1. 사용자가 브라우저 자동 번역 사용을 확인했다. React의 `removeChild` 오류와 일치하는 알려진 경로다. 한국어 문서 언어, `translate=no`, `notranslate`, Google 번역 제외 메타를 적용했다. React의 삭제 함수를 덮어쓰거나 오류를 숨기지 않았다. 이미 번역된 화면은 자동 번역 해제 후 새로고침해야 한다. 강제 번역 및 확장 프로그램까지 차단한다는 보장은 없다.
2. 로그의 BITX 오류는 Yahoo OHLCV 정리 중 `pd.to_numeric`에 2차원 표가 넘어간 것이다. 다중 티커 열을 무조건 평탄화하지 않고 요청 티커를 먼저 선택한다. 동일한 중복 열만 축소하며 충돌하는 중복 열/잘못된 티커 응답은 거부한다. 실제 Cloud 응답 원본은 로그에 없어 합성 다중 티커 응답으로 재현했다.
3. 작업 스레드의 가격 캐시가 Streamlit 로딩 UI를 만들지 않도록 수정했다. 로그의 `NoSessionContext` 경로에 대응한다. 정상 가격/판정 계산식은 변경하지 않았다.
4. 키움 조회 전용 시장 패널을 공통 모듈로 분리해 오늘점검과 돈흐름 화면에 연결했다. 거래대금, 테마별 상승 비율, 선택 테마 구성종목, 업종별 순매수를 제공한다. 자료 부족/인증/IP/호출 제한/시간 초과를 정상 수치로 바꾸지 않는다.
5. 종목명이 있는 국내 뉴스 검색은 불필요한 Yahoo 종목명 조회를 생략한다. 접미사 없는 국내 코드도 한국 뉴스로 검색한다. 미래 날짜 기사를 최근 뉴스에서 제외한다. 최근 48시간 직접 보도와 가격 등락을 나란히 표시하되 제목만으로 등락 원인을 확정하지 않는다.

## API 검토

2026-10-13 공식 저장소 명세 337개 API를 확인했다. 국내뿐 아니라 미국주식 시세/종목/업종 조회가 있다. 이번에는 검증 범위를 국내 read-only 4종에 한정했다. 뉴스 이름의 API는 찾지 못했다. CLI는 호출 도구이지 뉴스/원인 해석을 자동으로 제공하는 별도 자료 공급원이 아니다.

| API | 용도 | 단위/범위 |
| --- | --- | --- |
| ka10032 | 거래대금 상위 | KRX, 관리종목 제외, 백만원/주 |
| ka90001 | 테마 그룹 | 당일 등락률, 10일 기간수익률, 상승/하락 종목 수 |
| ka90002 | 선택 테마 구성종목 | 코드/종목명, 등락률, 기간수익률, 주 |
| ka10051 | 업종별 투자자 순매수 | KOSPI/KOSDAQ 구분, 금액 기준 억원 |

- 첫 페이지만 조회하며 표시는 최대 30행. 전체 시장을 모두 조사했다고 표시하지 않는다.
- 거래대금은 순매수가 아니다. 두 수치를 합산하지 않는다.
- 기존 매수 승인/목표비중/주문/보유 정보에는 쓰지 않는다. 수급을 기존 점수에 추가하려면 단위·기준일·종목 연결부터 별도 검증이 필요하다.
- 데이터 수집 시각을 시세 기준일로 대체하지 않는다. 모의 응답은 실전 표에서 제외한다.
- 응답 정규화에서 누락 값은 결측으로 남기며, 잘못된 종목 수로 확산률을 만들지 않는다.

## 검증과 한계

- 전체 회귀 725개 통과, 기존 pykrx deprecation 경고 1개.
- 컴파일 및 공백 오류 검사 통과.
- 네트워크 없는 Streamlit 화면 테스트: 최초 미조회, 정상 조회, 다른 테마/시장 선택 시 이전 결과 제거, 뉴스 없음, 한 공급 경로의 timeout 후 다른 표 유지.
- 실제 브라우저에서 분리된 테스트 화면의 버튼/표/재실행 및 문서 번역 제외 속성을 확인했다. 확인 시 브라우저 console error 없음. 전체 실사용 계정 화면이나 Google 강제 번역 재현까지 검증한 것은 아니다.
- 사용자 키/계좌는 열람하지 않았으며 실제 키움 인증 성공/실제 시세의 정확성을 확인하지 않았다. 배포 후 연결 상태와 원천 수치를 대조해야 한다.
- Cloud 배포/커밋/푸시는 수행하지 않았다. 새 공통 모듈도 app.py와 함께 배포해야 한다.
- 회귀 테스트 통과는 투자 적중률이나 실전 수익률 검증이 아니다.
