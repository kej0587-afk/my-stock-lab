# 정밀관측소 분기 실적·예상 대조

## 연결 범위

- 밸류 패널의 별도 펼침 영역에 과거 EPS 실제·예상, 보고 매출과 현재 분기
  EPS·매출 예상 표를 연결한다. 같은 결과를 밸류 검토 ZIP에 보존한다.
- 기존 등급, 재무점수, 후보품질, 최종체크와 실행 게이트에는 점수를 더하지 않는다.
  오늘점검 전체 종목 배치와 최종체크에는 추가 요청이 없다.
- Yahoo quoteSummary의 earningsHistory/earningsTrend/분기 손익계산서/통화/종목
  식별자를 한 요청으로 조회한다. 기존 yfinance 인증·TLS 세션을 사용하며,
  원응답의 분기 종료일·통화·GAAP/조정 기준을 보존한다.
- 공통 YahooMetadataReader를 이용해 15분 성공 캐시, 60초 실패 대기와
  전역 429 차단을 공유한다. 실패 후 이전 성공값은 정상 비교에 사용하지 않는다.

## 혼동 방지

- EPS는 earningsHistory의 동일 행, 동일 분기 종료일 실제·예상만 대응한다.
  통화·회계기준이 없으면 차이는 보류한다. 손실 EPS와 0은 유효값이다.
- 공급자 실제−예상 단순 차이이며 공식 실적 서프라이즈 확인이 아니다.
  예상 산출시각과 발표일은 미제공이고 조회시각과 분기 종료일로 대체하지 않는다.
- 현재 0q/+1q 예상은 과거 실적표에 역으로 채우지 않는다. 연간 0y/+1y도
  분기 예상으로 쓰지 않는다. 과거 매출 예상이 없으면 미제공을 유지한다.
- 저장 SEC 공시 매출은 정확한 종료일, 단일 분기 여부, 통화와 공시 근거가
  있는 경우에만 공급자 보고 매출과 대조한다. EPS를 순이익으로 대신하지 않는다.
- 저장 재무가 공급자 최신 실적보다 오래되면 갱신 확인 필요만 표시한다.
  수동점수와 저장 원자료는 바꾸지 않는다.
- ETF는 기업 실적 요청을 하지 않는다. 비지원/누락 종목은 링크나 0으로
  연결된 것처럼 만들지 않는다.

## 확인

- 실제 API: GOOGL의 GAAP, MSFT의 nongaap 구분과 2026-09-30 실적,
  2026-12-31 예상 종료일을 확인했다. MSFT FY2027 Q1을 달력 Q3으로
  이름 붙이지 않고 실제 종료일로 표시한다.
- 단독 API 측정: GOOGL 첫 조회 1.023초, 캐시 0.0005초. MSFT 첫 조회
  0.130초, 캐시 0.0005초. 전체 앱/오늘점검 속도 개선 측정은 아니다.
- 기간 충돌, 0/손실/누락, 통화/회계기준 누락, 오래된 응답, 429,
  저장 SEC 매출 대조, ETF 제외, 표/검토 파일/점수 불변 회귀 검사를 추가했다.
- 최종 관련 검사 170개 통과(25.41초), 전체 검사 4,246개 통과·1개 건너뜀·
  하위 테스트 18개 통과(190.78초). Streamlit 실제 표 렌더링도 확인했다.
- 독립 리뷰의 공시 근거 기간/산출값 검증, EPS 종료일로 인한 잘못된 갱신
  경고, 잘못된 공급자 period 자료형 오류를 보완하고 8개 별도 재현을 통과했다.

## 남은 제한

공식 SEC EPS와 공급자 EPS의 GAAP/조정·주식수 기준 대조, 발표 당시 매출
컨센서스 이력 저장, 한국 종목별 상세 예상 출처 확장은 아직 별도 작업이다.
이번 표가 모든 종목의 실시간 컨센서스나 공식 발표 자동 검증을 보장하지 않는다.
