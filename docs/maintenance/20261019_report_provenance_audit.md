## 실제 실행/캐시 경로

- `app.py:render_today_market_memo_panel` → `_collect_today_report_context` →
  `stock_lab_core.market_memo.build_auto_market_memo` →
  `report_evidence.report_sections`. 별도 브리핑 생성 헬퍼도 같은 함수를 호출한다.
- 원자료는 기존 돈흐름/오늘점검 스냅샷을 사용한다. 보고서 생성이
  오늘점검 86종목 재계산을 의미하지 않는다.
- 자동 생성 Markdown은 `today_market_memo_text`에 저장된다.
  이전에는 10/18 문자열 버전이 고정되어 새 코드 배포 시 무효화되지 않았다.
- 성능표는 `summary` 측정이 발생한 실행만 저장한다. 그 외 재실행/다운로드는
  이전 측정을 그대로 사용한다. 의도된 동작이지만 측정 시각과 재사용 표시가 빠졌다.

## 이번 수정

- 보고서 마지막 줄: 기준 커밋, 실제 로드한 소스 해시, 실행/렌더 경로,
  생성 ID·시각, 연결된 점검 측정 ID. 개인 키나 환경변수는 읽거나 출력하지 않는다.
- 모듈 로드 때 파일 해시를 보관한다. 현재 디스크와 다르면 앱 재시작을 안내하고
  자동 생성 버튼을 비활성화한다. 강제 reload는 하지 않는다.
- 자동 Markdown 캐시는 로드된 코드 해시가 바뀌면 무효화한다. 수동 메모는 보존한다.
- 성능 JSON에는 측정 ID·시작/완료 시각·범위·빌드·재사용 여부를 추가한다.
  기존 측정에 새 측정 ID나 현재 빌드를 붙이지 않는다.
- 한국 기준 거래일 당일 15:30 이후 기사는 제목과 무관하게 마감 후 맥락으로
  분류한다. 다음 날짜의 기사는 다음 세션 재료로 유지한다.
  발행시각 누락·미래 기사는 제외하며, 마감 후 발행 사실을 장중 원인으로 승격하지 않는다.
