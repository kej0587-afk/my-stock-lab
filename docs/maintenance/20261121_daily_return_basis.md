## 확인한 문제와 범위

판정의 `regular_day_ret`은 원자료 마지막 두 Close의 비율이다. 원자료에 장중
일봉이 있으면 그 일봉이 포함된다. `전일등락`이라는 기존 이름만으로는 비교한
날짜나 봉의 완료 여부를 알 수 없었다. `live_ref_ret`은 선택 현재가와 원자료
마지막 Close의 비교이며, 보고서의 확정 종가 수익률과 다른 값일 수 있다.

`signal_basis`에서 비교에 실제 사용된 마지막 두 행의 날짜를 읽어 설명만 추가한다.
달력상 전 거래일을 만들어 넣거나 가격·판정·데이터 프레임을 바꾸지 않는다.

- **등락비교기준:** 원자료 Close의 이전 행 날짜 → 마지막 행 날짜.
- **등락봉시간상태:** 계산시각과 기존 거래소 달력을 대조한 상태. 장중이면
  미확정, 마감시각이 지났어도 공급처의 확정 완료까지 인증하지 않는다.
- **최신가비교기준:** 선택 현재가 / 마지막 원자료 Close. 기존에 수집한 시세
  관측시각·세션만 사용하고, 계산시각을 공급 시세시각으로 바꾸지 않는다.

정밀관측소 근거 표·전술 지표·종합 설명에 표시하고, 오늘점검·전광판 상세 표에는
같은 `input_basis` 열을 연결했다. 새 외부 요청이나 TTL 변경은 없다.
기존 숫자·`day_ret_label`·점수·위험 근거 문장·매매 허용 기준은 변경하지 않는다.
날짜 순서/가격이 불명확하거나 비교 행이 부족하면 비교쌍을 미확인으로 둔다.
선물·FX·암호화폐 등 이 주식 달력 범위 밖 종목의 완료 상태는 추정하지 않는다.
