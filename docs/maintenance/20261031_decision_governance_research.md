# 후보 품질과 최종 체크의 역할 재설계

## 객관적 평가

현재 설계는 개인용 점검 체크리스트로서 장점이 있다. 기업의 상태, 가격 조건, 비중·시장 위험을 함께 보려는 의도는 타당하다. 다만 투자 성과로 검증된 모형은 아니며, 사람이 두 번 독립적으로 검토하는 것과 같은 프로그램이 같은 숫자를 두 번 세는 것은 다르다.

같은 조건의 반복도 의도적으로 높은 가중치를 주려는 설계일 수 있어 그 자체만으로 오류라고 단정할 수 없다. 다만 그 경우에는 '독립 위험 2개'가 아니라 '한 위험의 가중치 2'라고 표현해야 한다. 현재 문제는 이 구분과 가중치의 검증 근거가 명확하지 않다는 점이다.

| 평가 항목 | 판단 | 이유 |
| --- | --- | --- |
| 안전관리자/현장소장 역할 구분 | 유지할 가치가 있음 | 기업의 상태와 실제 투입 조건은 다른 질문 |
| 후보품질 명칭 | 평가 범위와 불일치 | 기존 점수에는 RS·MFI·MACD·추세가 포함되어 순수 기업 품질은 아님 |
| 재무 근거 구성 | 정확히 같은 근거의 중복 가중치 존재 | 분기 매출 증가/모멘텀, 이익 증가/모멘텀 등 |
| 최종 체크 집계 | 수정 필요 | 시스템 종합 경고와 그 경고의 개별 사유를 별도 위험으로 합산 |
| 결측 처리 | 수정 필요 | 미수집을 과열 없음·매크로 통과로 세는 경우가 있음 |
| 예외 정책 | 수정 필요 | 레버리지 회복 특례가 로컬 차단보다 먼저 선택될 수 있음 |
| 매매 임계값 | 우수성을 판단할 근거 부족 | 45/25/5, 차단 2건 등의 투자 성과·오탐률 비교가 없음 |

역할 비유는 유용하지만 실제 금융기관의 법적 직무나 승인 체계를 그대로 구현했다는 뜻은 아니다. 앱의 최종 체크도 사용자의 최종 투자 결정을 대신하지 않는다.

## 공개 방법론과 비교

금융회사마다 방식은 다르다. 아래는 공개된 지수 방법론·교육 자료의 사례이며 모든 증권사의 내부 절차를 대표하지 않는다.

| 공개 사례 | 확인한 방법 | 이 앱에 적용할 점 |
| --- | --- | --- |
| MSCI Quality | 높은 ROE, 이익 성장 안정성, 낮은 레버리지 등 재무 변수로 품질 평가 | 기업 품질을 가격 타점과 구분. 자료가 없으면 좋은 품질로 간주하지 않음 |
| S&P Quality | ROE·발생액 비율·재무 레버리지로 품질을 산출하고, 선정·편입 비중 규칙은 별도로 정의 | 품질 점수와 계좌 내 투입량·제약을 하나의 합계로 뒤섞지 않음 |
| Nifty Momentum Quality | 모멘텀과 품질을 의도적으로 결합한 전략도 존재 | 혼합 자체는 오류가 아님. 기존 혼합 등급을 순수 기업 품질이라고 부르는 것이 문제 |
| CFA 포트폴리오 과정 | 투자 목적·정책, 자산배분, 증권분석, 포트폴리오 구성, 모니터링·성과 측정을 구분 | 종목 선별과 계좌 위험 허용량의 책임을 구분 |

MSCI의 품질 변수와 2025년부터 ROE·D/E를 필수 자료로 취급하는 변경은 각각 [MSCI World Quality](https://www.msci.com/indexes/index/702787), [MSCI 공식 변경 공지](https://app2.msci.com/webapp/index_ann/DocGet?format=html&lang=en&pub_key=Rsk%2FI1RPQbI%3D)에서 확인했다. 이 앱은 5년 EPS 변동성·동일 모집단 상대평가 자료를 충분히 확보하지 않았으므로 MSCI 모형을 복제했다고 표시하지 않는다.

S&P의 세 품질 변수와 구성 규칙은 [S&P Quality Indices Methodology, 2025-09](https://www.spglobal.com/spdji/en/documents/methodologies/methodology-sp-quality-indices.pdf)에 공개되어 있다. 이 앱의 OCF 양수 여부는 S&P의 발생액 비율과 동일한 지표가 아니다.

품질과 모멘텀의 결합 사례는 [NSE Indices 공식 Nifty Total Market Momentum Quality 50](https://www.niftyindices.com/indices/equity/strategy-indices/nifty-total-market-momentum-quality-50)에 제시되어 있다. 따라서 기존 혼합 후보등급은 삭제하지 않고 명칭과 위치를 구분한다.

[CFA 포트폴리오 과정](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/portfolio-management-overview), [CFA 자산배분·위험 예산](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/overview-asset-allocation)

## 채택한 구조

다음 구분은 위 자료를 참고한 **이 앱을 위한 설계 제안**이다. 기관 공통 표준이라는 뜻은 아니다.

| 단계 | 책임 | 하지 않는 일 |
| --- | --- | --- |
| 자료 확인 | 가격·재무 기간·필수 지표·출처 확인 | 미수집을 정상값으로 채우지 않음 |
| 기업 품질 / 상품 구조 | 현행 재무 1~4점과 근거·수동 지정 구분. ETF는 기업재무 대신 상품 구조 구분 | 시장 하락만으로 기업 품질 점수를 다시 감점하지 않음 |
| 기술 타점 | 현재 가격·추세·과열·손익비·상위 시간대 확인 | 높은 품질만으로 진입 조건을 통과시키지 않음 |
| 계좌 실행 제한 | 시장 모드·비중·자료 상태 및 개별 제한을 통합 | 같은 위험을 요약과 상세에서 두 번 집계하지 않음 |
| 사용자 최종 결정 | 투자 가정·손실 감내·실행 여부 결정 | 앱이 주문을 자동 실행하지 않음 |

기존 기술·재무 혼합 후보등급은 종합 순위로 유지하고 상세 영역으로 이동한다. 기업 품질 표시는 재무 점수만 사용한다. 기존 혼합 점수를 기업 품질에 다시 더하지 않는다. 차트 0~100 성적표도 매매 점수에 가산하지 않는다.

## 이번에 실제 적용한 변경

1. 게이트 분기에 안정적인 근거 ID를 부여했다. MTF·비중·시장·R/R·과열·진입조건·돈흐름 등을 설명 문장과 독립적으로 전달한다.
2. 최종 체크는 같은 ID의 가장 강한 상태를 한 번만 집계한다. 정상 시스템 게이트는 종합 요약이므로 별도 통과 표로 더하지 않는다.
3. 원래 점검행과 판정 문구는 보존하고, 표에 독립근거/중복 제외/요약을 표시한다. ID가 없는 과거 결과는 설명 문구만 보고 임의로 경고를 합치지 않는다.
4. RSI/MFI/%B·매크로·R/R 등의 미확인을 통과와 구분한다. 알려진 과열은 유지하며 일부 자료 누락도 별도로 추적한다.
5. 실행성 결론은 게이트 실행가능, 독립 차단 0건, 핵심 미확인 0건을 모두 만족해야 한다. 레버리지 특례도 이 조건을 우회하지 못한다.
6. 기업 품질·기술 타점·계좌 실행 제한을 별도 표로 연결했다. 상세 문구와 검토 ZIP에도 근거 메타데이터를 남긴다.
7. 저장 게이트가 실행가능이어도 현재 시스템 행에 차단·주의·미확인이 있으면 요약으로 제외하지 않는다. 저장 결과와 현재 신호가 충돌할 때 현재 경고를 지우지 않는 회귀 사례도 검증한다.

예를 들어 MTF 경고 하나가 시스템 요약과 상세에 각각 표시돼도 독립 차단은 1건이다. 결과는 기존의 '대기' 문구로 정리되며 게이트 방어는 유지한다. MTF와 별도의 매크로 차단이 있으면 독립 차단은 2건이고 기존 '매수 금지'를 유지한다. 레버리지 회복 신호가 좋아도 비중·매크로 등 실제 차단을 무시하지 않는다.

시장 위험 산식의 임계값과 통합 중단 정책을 이번에 완화하지 않았다. 같은 경고의 중복 제거와 별개로, 유효한 시장 방어를 자동 해제하는 변경은 아니다.

## 재무 가중치는 왜 비교 모드인가

정확히 같은 판정조건만 다음 가족으로 묶었다. 단순히 상관관계가 높다는 이유로 모든 성장·수익성 항목을 하나로 합치지 않는다.

| 같은 근거 가족 | 기존 합산 가중치 | 비교안 가중치 |
| --- | ---: | ---: |
| 분기 매출 증가 / 매출 모멘텀 | 3+2 | 3 |
| 분기 영업이익 증가 / 모멘텀 | 3+2 | 3 |
| 분기 OCF 양수 관련 3항목 | 3+2+1 | 3 |
| 분기 이익률 관련 2항목 | 2+1 | 2 |
| 분기 부채 안정 관련 2항목 | 2+1 | 2 |

금융업에서 단순 부채비율을 제외하고 자본·순이익을 확인하는 예외는 별도 취급한다. 동일 가족 안의 충돌·미확인은 좋은 항목만 선택해 점수를 올리지 않는다. 위험 플래그는 독립적으로 보존한다.

일반 구성의 명목 최대치는 **62→53**이다. 운영 GOOGL의 같은 저장 근거에서는 기존 순점수 **52/62**, 중복 제거 비교안 **47/53**이었다. 단순 최대치 환산은 약 **54.98/62**지만, 이는 범위 변환일 뿐 등급 검증이 아니다. 같은 45/25/5를 원점수 47에 바로 적용하거나 환산만으로 새 등급이 우수하다고 주장할 수 없다.

따라서 **중복 비교 표·근거 가족·검토 파일 연결은 적용하되 저장 재무 1~4점과 기존 등급 경계는 이번에 교체하지 않았다.** 수동 지정 점수도 유지한다. 중복 판정을 합산하는 문제를 숨기는 대신 대안을 계산·저장 가능한 비교 자료로 노출한 단계다.
