# C-12: 익절 조건인데 월적립 1.0배를 받는 보유 상태 (2026-11-26)

분석만 했습니다. 판정·배율·게이트는 바꾸지 않았습니다. 사용자 결정 전입니다.

## 0. 요약
- **익절 조건**: 개별주 보유, MFI 80 이상, %B 0.9 초과, 평단 대비 +20% 초과.
- **재생 결과**: 현재 코드로 다시 재생해도 A-4와 같았습니다.
  - 익절 조건 상태는 473개입니다.
  - 그중 52개가 월적립 1.0배(추가매수 방향)를 받습니다. 코드는 LEADER_MA5_PULLBACK_ENTRY 35개, HOLDING_QUALITY_RECOVERY_CANDIDATE 16개, HOLDING_QUALITY_RECOVERY_SCOUT 1개입니다.
- **실제 집행은 거의 없습니다.** C-6 이후 개별주 월적립은 Today 게이트가 실행가능일 때만 집행됩니다(C1).
  - 52개 중 실행가능은 **2개**뿐입니다(LLY 2021-10-25, 000270.KS 2019-11-22. 평단 +25/+50/+100% 모두 같음).
  - 나머지 50개는 계획표에 1.0배 금액이 보이지만 집행되지 않습니다. 사유는 "R/R 목표가가 투영상단 · 과열/추격금지" 29개, 상위 시간대 추세훼손 11개 등입니다.
- **이후 수익률**: 52개는 다른 익절 조건 상태(421개)보다 약간 낮았습니다.
  - 20일: +1.0% vs +2.2%
  - 60일: +6.9% vs +8.1%
  - 120일: +12.0% vs +20.0%
  - 60일 뒤 손실 비율은 42% vs 40%로 비슷했습니다.

## 1. 방법
- A-4 재생과 같은 조건입니다: 개별주 66종(미국 33, 국내 33), 2015–2026, 5거래일 간격, 평단 대비 +25% / +50% / +100% 보유 가정.
- 매크로는 1.0, 비중은 5/10, 시장 가드는 붙이지 않았습니다. 익절 조건이 참인 상태만 모았습니다(473개 × 평단 3종 = 1,419행).
- 엔진, Today 경로(상위 시간대 가드 → 판정 흐름 → 실행 게이트), 월적립 배율을 현재 `main` 코드로 계산했습니다.
