# SOXS의 SOXL 회복 프로필 오연결 수정

- 시작 main661f8daf/로컬 일치, 미커밋 없음. 수정 범위는 app.py의 프로필 선택 함수뿐이다.
- 원인: Direxion/Semiconductor/3X가 포함된 상품명에 상승·하락 방향 검증이 없어 SOXS 전체 상품명이
  SOXL 프로필을 반환했다. 이전 운영 ZIP의 SOXL 회복축/회복3/6 표시는 이 잘못된 연결이었다.
- SOXS 티커는 상품명이 비었거나 잘렸거나 Bull로 오기돼도 미등록 프로필을 반환한다.
  상품명 fallback에서도 Bear/Inverse/인버스를 제외한다. SOXL 명시 티커와 기존 정상 fallback은 유지.
- 별도 인버스 회복·진입 전략을 새로 만들지 않았다. SOXS는 기존 공통 판정/시장방어 경로를 따르며,
  SOXL 전용 회복 체크·L3 조회·재진입 시뮬레이터를 빌려 쓰지 않는다.
- 잘못 추가되던 leveraged_precision_profile 등 SOXL 파생 필드/전용 표시가 사라지는 것은 의도된 변화다.
  기존 원판정을 SOXL 전용 문구로 덮어쓰지 않으므로 전용 문구까지 이전과 같다고 주장하지 않는다.
  시장방어·L3 계산식·예산/회차 저장·월적립·점수 산식·TTL은 수정하지 않았다.
