# 돈흐름 레이더·섹터 능력치 감사

## 평가

가격·거래량 기반 후보 발굴과 최종 매수 게이트를 분리하는 구조는 유지한다.
다만 능력치의 원천 관측 신호가 최종 후보판보다 우호적으로 표시될 수 있었고,
대표주·기간·중복을 섞는 집계 오류가 있었다. 새 점수나 매매 조건을 추가하기
전에 이 경로를 수정했다. 기존 후보 등급·재무점수·매매 임계값은 변경하지 않았다.

이 점수는 실제 ETF 자금 순유입, 수익 확률 또는 백테스트 검증 성과가 아니다.
기관 모멘텀 방법론에는 기간·변동성 조정·편입 규칙이 명시돼 있다. 이를 본 앱의
수익 예측력으로 가져오거나 현재 가중치를 임의로 교체하지 않았다.

## 확인·수정

| 항목 | 재현과 처리 |
| --- | --- |
| 후보판과 능력치 | 모더나는 후보판 눌림대기인데 능력치 action은 원천 ETF 신호로 정밀관측이었다. 원천 관측신호와 확정 후보판 행동을 분리했다. 동일 관측 내 충돌은 보수적으로, 서로 다른 관측은 유효 후보를 기준으로 선택한다. |
| 대표주 분류 | 대표주 이름의 ‘에너지’가 2차전지 분류를 덮거나, 넓은 연결테마가 DR호튼을 전력·인프라로 옮겼다. 명시된 세부축·테마를 먼저 사용한다. |
| 대표주 표시 | 정적 기준 대표축과 실제 포착종목은 별개다. ETF와 등락률 `-`인 미검증 클러스터 이름은 포착종목에서 제외한다. 순서는 확정 행동·기간 수익률·점수로 고정한다. |
| 중복 | 같은 CIBR 행을 3개 복제하면 확산 3.3이 10이 되었다. 종목/테마 관측 키로 중복을 합치고, 확정 행동은 따로 보존한다. |
| 기간 | 5D 확산에 1M-only 행을 포함하지 않는다. 실제 `3M수익률` 열을 읽으며 RS를 절대 수익률 대체값으로 사용하지 않는다. |
| 결측 | 강도·확산·단기·모멘텀 결측을 5점, 안정도를 7점으로 채우던 경로를 제거한다. 미산출 축과 유효 축 수를 표시하고 불완전 종합점수는 미산출로 둔다. |
| 재사용 | 새 ETF 날짜에 과거 테마를 붙이지 않는다. 점수 있는 각 한국/미국 행의 실제 기준일을 확인한다. 가격부족·미산출 실패 행은 신호가 아니며 별도 누락 수로 표시한다. |
| 기준일 | 수집·계산 시각과 실제 가격 기준일을 구분한다. 원자료별 날짜 범위·이전일 자료·기준일 미확인 수를 표시한다. |
| RS 누락 | 벤치마크 조회 실패를 수익률 0으로 바꾸지 않는다. 상대강도·사분면은 미확인, 진입검토는 관망으로 남긴다. |

같은 섹터 카드가 상단 돈흐름 능력치에도 전달되는 기존 연결은 유지한다.
글로벌 복합 테마를 대표주 한 개로 한국/미국에 강제 배정하지 않는다.

## 실자료·성능

11/1 로컬 실제 API 조회, UI·로그인 초기화 제외. 원자료는 ETF 109행,
테마 475행이며 유효 가격 기준일은 2026-10-30이었다. 테마 19행은
가격·점수가 없었으므로 정상 신호로 간주하지 않는다.

| 단계 | 벽시간 |
| --- | ---: |
| 원자료 수집·계산 | 19.693초 |
| 실행 후보판 구성 | 1.934초 |
| 섹터 능력치 | 0.045초 |
| 합계 | 21.672초 |

함수 누적시간은 중첩·병렬 호출을 포함하므로 위 벽시간에 다시 더하지 않는다.
`get_money_flow_ohlc` 486회는 래퍼 호출 수이며 486번의 독립 HTTP 요청을
뜻하지 않는다. 병목은 원자료 수집 쪽이다.

SOXX, IBB, IGV, 069500.KS, MRNA, DHI, 005930.KS의 종가·1D·5D를
가격 이력으로 다시 계산했고 기준일과 수치가 일치했다. 같은 공급자 기반의
파이프라인 비교이며 독립 공급자로 전 종목을 인증한 것은 아니다.

저장한 동일 실자료 5회 재생에서 능력치 중앙값은 수정 전 0.0424초,
수정 후 0.0482초였다. 추가 네트워크 조회는 없다. 정확도 수정 비용은 약
6ms이며 전체 Cloud 속도 개선율을 주장하지 않는다. 정상 벤치마크가 있는
기존 로테이션 수치도 정확히 일치했다.

## 큰 함수 분리

돈흐름 화면의 최대 함수 `render_money_flow_etf_section` 594줄을 232줄로
분리했다. 순위·해석 72줄, 히트맵/사분면 127줄, 분포 167줄의 헬퍼로
옮겼으며 계산식·차트·선택 키·세션 상태·표시 순서는 유지한다.
원 AST 블록과 동일함을 검사하고, 이전 커밋과 전체/한국/미국/매크로
화면의 UI 호출·그림 JSON·선택 상태, 빈 자료/미실행 경로를 대조한다.

최종 전체 회귀는 4,298개 통과·1개 건너뜀·하위 테스트 18개 통과
(206.79초), 최종 집중 회귀는 80개 통과(27.85초)했다. 독립 리뷰의
중복 후 추격금지 안전 패널티 누락도 보완해 6.0→4.8 재현을 확인했다.

전체 앱 리팩토링 완료는 아니다. 현재 최대 함수는 포트폴리오 탭(839줄)이고,
정밀판정 함수(798줄)와 테마 화면(520줄)은 이번에 함께 이동하지 않았다.

## 남은 범위

- 공식 EPS·과거 매출 컨센서스 대조는 앞선 분기 실적 작업의 별도 다음 단계다.
- 실제 펀드 순유입과 이 후보 점수의 예측력 검증은 별도 데이터·백테스트가 필요하다.
- 코인 24시간 시장과 모든 해외 거래소를 위 7종목 표본 검증에 포함하지 않았다.
- 현재 원천 테마 유니버스의 업종 정의와 정적 기준 대표축은 정기 갱신 대상이며,
  자동으로 실제 지수 편입종목/시총 상위와 같다고 취급하지 않는다.
