# A-5 / A-6 매크로 결측 처리 (2026-11-25, 사용자 승인안 A)

승인 전 비교 보고서(프로젝트 파일 reports/20261125_a5_a6_macro_missing.md)의 V2안을 그대로 구현했다.

## 1. 원칙 (사용자 승인 11-25)

1. 매크로 데이터 결측은 위험으로 추정하지도, 정상으로 간주하지도 않는다.
2. 핵심 매크로가 결측이면 종목 판정은 매크로 영향 없이 계산한다. 위험점수 1.5 가정 없음, 매크로 감점 가정 없음,
   `< 4.5` 같은 조건 때문에 회복 후보가 구조훼손으로 바뀌지 않는다.
3. 실행 단계는 `데이터확인 · 매크로 미확인`. 이미 방어우선인 종목은 방어우선 유지(더 강한 기존 위험 판단 우선).
4. 핵심 매크로 4개: 미국 10년물 금리, VIX, USD/KRW, 유가. 하나라도 유효값이 없으면 매크로 상태 UNKNOWN.
   빠진 항목을 화면과 진단에 표시한다(예: `매크로 미확인 · USD/KRW 데이터 누락`).
5. MOVE 결측은 +0.5를 넣지 않고 `MOVE 미확인`으로 표시만 한다(0점도 +0.5점도 아님). 나머지 4개로 계산한다.
6. 코어 ETF 정기 적립도 이번에는 예외 없이 데이터확인. "정기 코어 적립은 매크로 결측 시에도 허용할 것인가"는 C-13.
7. 데이터가 돌아오면 즉시 기존 매크로 계산·판정·게이트로 돌아간다. 결측 상태를 캐시에 남기지 않는다.
8. 진단용으로 `macro_data_status`, `macro_missing_components`, `last_complete_macro_at`을 남긴다.
   마지막 정상값을 판정에 다시 쓰지 않고, 새 fallback 정책을 만들지 않는다.
