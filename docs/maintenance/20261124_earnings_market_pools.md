# 공시 실적 수집: 시장별 작업자 분리 (상태표 #5)

작성 2026-11-24 KST · 시작 `90d0cd1c`

## 확인한 원인

- `collect_filing_earnings`는 국내(DART)·미국(SEC) 발행사를 **작업자 3개짜리 한 묶음**에서 처리하고,
  24초 공용 한도(`MAX_SECONDS`)를 넘으면 남은 발행사를 `collection_time_budget`으로 보류한다.
- 미국 작업은 SEC 공정 접근 간격(요청 사이 0.2초, 공용 잠금) 때문에 대기 시간이 길다. 그동안 작업자를 붙잡아
  국내 발행사가 SEC 대기 뒤에 줄을 섰다. DART 쪽은 기다릴 이유가 없는데 기다린 것이 낭비였다.
- 운영 기준선(리부트 직후 빈 캐시, 2026-11-24 PR #4 배포 후 생성): 점검 78개 중 **51개 보류**(국내·미국 모두).

## 변경

- 시장별 작업자 묶음 2개(`MARKET_WORKERS = 3`씩). 국내는 국내 묶음, 미국은 미국 묶음에서 처리한다.
- 바꾸지 않은 것: 24초 공용 한도, SEC 0.2초 간격과 공용 잠금, 공급처별 동시 처리 최대 3개(DART 3, SEC 3),
  재시도 횟수, 요청 timeout, 캐시 TTL(600초/실패 90초/기업코드 86400초), 검증 기준, 결과 순서.

## 검증

  시작하는지(이전 코드는 실패), SEC 동시 처리 최대 3, 결과 순서 유지.
- 실적·SEC·DART 묶음: 714 통과 · 5 실패(수정 전과 같은 목록). report 게이트 208 통과(`report_cm5saoul`).
- 운영 비교(같은 조건: 리부트 직후 빈 캐시, 같은 78개)는 HANDOFF의 운영 확인 항목에 기록한다.
