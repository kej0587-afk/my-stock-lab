# 시황 개편 1단계: 독자용 보고서 구역 재배치

작성 2026-11-24 KST · 시작 `36f7b425` · 근거: 2026-11-24 통합 시황 개편 요청서 4절·15절
(요청서 원문은 비공개 프로젝트 파일에 보관하며 저장소에 복사하지 않았다).

## 범위

`compose_reading_report`의 **구역 순서와 배치만** 바꿨다. 숫자 계산, 점수, 게이트,
판정 문구, 수집기, TTL은 바꾸지 않았다. 표는 기존처럼 복사만 한다.

## 새 순서

| 구분 | 구역 | 내용(기존 자료 재사용) |
| --- | --- | --- |
| A | 빠른 요약 | 시장별 세션·마지막 확정 종가, 시장 해석, 주요시장 지수표, 기존 실행 방향 한 줄, 기준일 지연·재계산 경고 |
| A | 지금 상태 3줄 | 기존 블록 그대로(제목 유지) |
| B1 | 지수 | 기존 지수표 |
| B2·B3 | 미국 시황 / 한국 시황 | 기존 내용. 한국 장중이거나 한국 마감 후·미국 장중이 아닐 때는 한국을 먼저 둔다 |
| B4 | 세계 시장과 국가 ETF | 관측실 국가 ETF 4개의 연결 상태(현재 모두 미연결), 현지 지수 미수집 명시 |
| B5~B8 | 매크로 | 기존 금리·환율·원자재·VIX/MOVE 표, 중앙은행 공식 발표, 금리·에너지 재료 |
| B10 | 물가·고용·소비·경기 | 기존 '최근 발표' 표(매크로 구역에서 이동) |
| B8·B9 | 관측실 지표 연결 상태 | 관측실 등록 지표마다 '본문 표시' 또는 '미연결' |
| B11 | 이번 주 테마 5개, 돈흐름 · 업종 순환 | 기존 내용 |
| B12 | 주요 기업과 사건 | 기존 '해외·공통 재료'(매크로 구역에서 이동) |
| B13 | 오늘의 판단, 포트폴리오 · 교체 검토 | 기존 판단·경계·계좌 범위 문장(맨 앞에서 이동), 기존 보유표 |
| B14 | 다음 일정 | 기존 내용 |
| C | 상세 근거 · 계산 기준 · 연결 상태 | 기존 그대로 |

중복 제거 대상 표(`MOVED_SECTIONS`)의 '경제지표' 목적지에 '물가·고용·소비·경기'를 추가해
최근 발표 행이 부록에 두 번 실리지 않게 했다. 새 구역 4개는 화면에서 접힌 상태로 시작한다.
'오늘의 판단'은 기존처럼 펼친 상태로 둔다.

## 바꾼 테스트(의도한 구조 변경)

- `test_report_reading`: 구역 순서 목록을 새 순서로 바꿨다.
- `test_report_evidence`: `매크로 < 지수` 순서 단언을 `빠른 요약 < 지수 < 매크로 < 포트폴리오`로 바꿨다.
- `test_report_v9_quality`: 최근 발표 행을 찾는 구역을 '물가·고용·소비·경기'로 바꿨다.
- `test_report_document`: 첫 화면에는 기존 실행 방향과 지연·재계산 경고가, '오늘의 판단'에는
  기존 점수식·경계·"보유 전량 매도 지시 아님" 문장이 모두 남는지 확인하도록 바꿨다.
  확인하는 값 자체는 줄이지 않았다.
