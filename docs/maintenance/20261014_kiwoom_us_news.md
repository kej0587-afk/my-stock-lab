# 2026-10-14 키움 미국 조회와 종목 뉴스

## 범위

- 키움 시장근거에 국내/미국 선택 추가. 미국은 현재가 종목정보(usa20100), 거래대금 상위 주식(usa20540), 업종별 기간 수익률(usa23000)만 사용한다.
- 계좌/주문 API, 보유 수량, 목표비중, 매매 판정 규칙은 변경하지 않는다. 새 자료를 돈흐름 순위나 실행 후보에 자동 합산하지 않는다.
- 기존 `[kiwoom]` 설정과 토큰을 재사용한다. 실전/모의 키와 환경은 일치해야 한다. 모의환경 성공 시세도 환경을 표시해 보여주며, 인증/API 거절은 숨기지 않는다.
- 거래소는 종목 조회에서 NASDAQ(ND), NYSE(NY), AMEX(NA)로 지정한다. 예: NVDA/ND, DELL/NY. 종목·거래소가 다른 응답은 폐기한다.
- 미국 가격은 USD, 거래량은 주, 거래대금은 천USD. 가격 부호는 절댓값, 수익률 부호는 유지한다. 응답에 없는 시세 기준시각을 조회시각으로 대신 만들지 않는다.

## 뉴스 수정

- 해당 버튼은 키움 뉴스 API가 아니라 공개 RSS를 검색한다. 확인한 공식 명세에서 뉴스 전용 API를 찾지 못했으므로 이를 구분해 표시한다.
- 여러 단어가 모두 들어가야 했던 검색보다 회사명 단독 검색을 우선한다. 종목 관련성·날짜·노이즈 필터는 유지한다.
- 키움이 제공한 영문 회사명을 사용하고 CORP/INC 등 법인 접미사를 정리한다. 이미 유효한 회사명이 있으면 Yahoo 조회를 생략한다.
- 성공 캐시 600초, 빈 결과는 60초. 뉴스 버튼은 선택 종목의 캐시만 지우고 재요청한다. 다른 화면 조작은 뉴스 요청을 반복하지 않는다.
- 조회 0건, 연결 실패, 원문/필터 통과 건수, 시간/요청 제한을 표시한다. 종목 변경 시 다른 종목의 저장된 뉴스를 붙이지 않는다.
- 최대 16회 요청, 20초가 지나면 추가 요청 중단(진행 중 요청의 타임아웃은 별도). RSS 응답을 닫는다.

## 검증과 한계

- 전체 pytest: 794개 통과, 기존 pykrx deprecation 경고 1개.
- Streamlit AppTest: 국내 기존 화면, 미국 시장 전환, 개별 티커/거래소 변경, 뉴스 실패 후 재시도.
- 공개 RSS 실조회: 삼성전자/엔비디아 각각 7건, 직접 뉴스 각각 4건. 이 실행에서는 각각 약 2초대였다. 상시 속도/가용성을 보장하는 수치는 아니다.
- 사용자 키 인증, Cloud 배포 및 실제 키움 미국 응답은 미검증. 공급자 계약 테스트는 공식 명세와 대체 응답을 사용했다.
- AI 요약 생성, 전체 뉴스 분류 개선, 테마/ETF 종목 확장은 이번 범위가 아니다.
