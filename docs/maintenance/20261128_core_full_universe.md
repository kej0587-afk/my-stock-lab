## 추가 사건이 이전 기록에 없던 이유

추가13종목을 같은 수정 전 게이트·같은 가격으로 오래된 `sim_core_first_buy.events_for`에
대입하니3사건만 나왔다. 그중 **11종목18사건**은 이 함수의 `closed.get(s) is not True`
조건 때문에 누락됐다. 이력이 게이트 시작 이후부터 있으면 Series가 bool dtype이 되어
`numpy.bool_(True)`를 Python `True`와 객체 동일성으로 비교할 때 거짓으로 판단했다.

- 전용 합성 테스트에서 수정 전 실패 재현 → 연구 helper를 결측 검사+bool 값 비교로 수정.
- 수정 후 추가13종목의21사건 키가 이번 재생성 결과와 전부 일치했다.
- 이번 비교기는 이미 값 기반 검사를 사용했다. 따라서 이 수정으로 **전후90사건 표가 다시 바뀐 것은 아니다**.
  누락을 확인한 경로는 오래된 연구 CLI이며 운영 투자판정의 누락으로 확대 해석하지 않는다.
- 나머지2종목3사건은 현재 입력에서는 이전 helper로도 잡힌다. 과거91목록/당시 원본을 복원하지 못했으므로
  이전 목록 차이인지 다른 자료 차이인지 단정하지 않는다.
