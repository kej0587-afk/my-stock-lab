# 기존 분석 차트 통합 및 120분봉 운영 확인

## 범위

PR #108은 연구 코드·테스트·결과·문서만 포함됨을 확인해 사용자 요청으로 병합했다
(merge `b3a78694`). 연구 결과는 모의검증 후보이며 운영 판정·월적립·L3에 적용하지 않는다.
차트 수정은 별도 PR이다. 상단 빠른 차트를 제거하고 기존 분석 차트 자리에 8개 봉 간격과
MA 입력·선별 표시·전일 일봉 MA 겹침·계정 저장을 통합했다.

기존 패턴·추세선·평행 채널·돌파/이탈·추정 매물대·SMC 렌더러를 재사용한다.
분봉은 선택 분봉의 구조 관찰이고, 분봉 가격이 기존 점수·계획·일/주/월 스냅샷을 덮어쓰지 않는다.
분봉 거래량은 50봉 평균/RVOL이며 일봉의 연간·분기 거래량 분류를 적용하지 않는다.
일봉 실행조건 체크표는 분봉에 섞지 않고 일봉을 선택했을 때 그대로 표시한다.

## 재현한 원인

- 운영에서 SOXL `60 → 120 → 5 → 120`을 직접 전환했다. 120 버튼은 선택됐지만 가격·거래량이 비었다.
- 운영 원자료 60분 5,055봉, 생성 120분 2,891봉으로 수집 실패는 아니었다.
- 기존 category 축 라벨이 연도 없는 `MM-DD HH:MM`이어서 서로 다른 해의 같은 날짜가 합쳐졌다.
  로컬 재조회 1,500봉은 1,102개 category가 되었는데 초기 표시 범위는 1259.5~1499.5였다.
  즉 자료가 있는 축 밖을 보여줬다. 연도 포함 라벨 및 원 분석 차트의 고유 봉 좌표로 해결했다.
- 기존 120분 묶음은 행 순번 2개씩이어서 중간 60분봉이 빠지면 이후 묶음 시각이 밀렸다.
  거래소 달력 개장 기준 버킷으로 변경했다. 마감 후 데이터는 제외하고 다음 거래일과 합치지 않는다.
- 일봉 MA 겹침에서 오늘 일봉이 아직 없을 때 하루 더 늦은 값을 쓰던 문제도 수정했다.
  해당 분봉 날짜보다 엄격히 이전인 마지막 완료 일봉까지만 사용한다.

## 원자료 감사

실행: `venv/Scripts/python.exe scripts/audit_analysis_chart.py`.
재현: 같은 명령에 `--offline` (보존된 `cache/unified_chart_audit/SOXL_60m.csv` 필요).
다른 PC에는 cache 파일이 없을 수 있으며 새 조회를 동일 스냅샷이라고 부르지 않는다.

2026-11-27 15:12 KST Yahoo 조회: 60분 5,085봉 → 120분 2,908봉, 마지막 2026-11-25 15:30 ET.
요청은 730일이지만 공급 응답 시작은 2023-12-29였다. 요청 기간과 실제 응답 범위를 구분한다.
원파일 SHA256 `efa54d580a71b7b31a3f34e58494b3999ceecd5f295bc435b31c5b68ac1eb32b`.

| 거래일 | 받은 60분 | 생성 120분 | 시작 시각 ET | 원본/집계 거래량 |
|---|---:|---:|---|---:|
| 2026-11-25 정상장 | 7 | 4 | 09:30 / 11:30 / 13:30 / 15:30 | 517,247,541 / 동일 |

단축장 원자료에는 마지막 12:30 원봉이 없었다. 이를 0이나 추정 봉으로 채우지 않으며
원봉 일부 미수집 구간으로 표시한다. 전체 응답에서 이런 불완전 구간 7개.
완전한 단축장 4개 원봉 → 2개 집계(마지막 90분), 정상장 7 → 4(마지막 30분)는 합성 고정입력 테스트로 별도 검증했다.
데이터가 부족한 1000선은 그리지 않지만 캔들과 거래량은 유지한다.

## 검증 및 대기

- 차트/집계/설정/기존 렌더러 테스트 30개 통과.
- 상위 함수 AST 비교: 변경은 `render_precision_candlestick_chart`만, 계산함수 그대로.
- 결정 회귀 1,669개 중 1,668개 통과, 1개는 분리된 함수의 위치를 검사하는 AST 테스트였다.
  원래 검증 의도를 유지해 추출된 helper의 완료 거래일 전달을 확인하도록 갱신했다.
  최종 `check_refactor --scope decision`: **1,669 통과**, 155.13초, `decision_f3imi7_s`.
  시나리오+새 차트 묶음 61 통과. 실패 스냅샷/투자 임계값을 재생성하지 않았다.
- 운영 배포 후 120 캔들·거래량과 일봉 레이어·설정 복원은 다음 확인 항목.
- 미국 장중 30초 갱신, 원천 체결 시세 지연, 실제 갤럭시 기기 시간은 운영 확인 대기.
  봉 시작 이후 경과시간을 공급 체결 지연으로 부르지 않는다.
