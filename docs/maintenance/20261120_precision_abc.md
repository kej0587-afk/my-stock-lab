# Four-Axis Conditional Management Plans

## 목적과 범위

시장방어는 신규 자금 투입 제한입니다. 보유분의 조건별 관리계획까지
설명을 중단하는 이유가 되어서는 안 됩니다. 이번 변경은 정밀관측소의
기존 관측 요약을 구조·가격·기간·유동성 대용치의 해석과 A/B/C 대응으로
연결합니다. Base: `0ab261bb`.

- A: 지지·회복 관찰. 상위 흐름과 같은 일봉의 위치를 대조합니다.
- B: 이탈·악화 대비. 기존 추세훼손/현재 확인된 매도 신호를 반대 근거로
  표시하고 보유 위험을 먼저 검토합니다. 자동 매도 명령이 아닙니다.
- C: 횡보 또는 방향·자료 확인 대기. 부족한 근거를 분리합니다.
- 각 안에 근거, 확인 조건, 보유분 관리, 신규 자금 제한, 원계획 가격,
  무효화·재검토 조건을 표시합니다.

기존 시장방어·최종 체크·투자 임계값·가격·주수는 그대로입니다.
패널의 A/B/C 우선 관찰 표시는 투자 등급이나 새로운 진입 허가가 아닙니다.
일봉 관리계획이며 SOXX 1시간/SOXL 5분 단타 계획과 분리됩니다.

## 구현 경계

- `precision_scenarios.py`: 기존 입력만 받는 순수 해석 모델과 표시 함수를
  분리했습니다. 새로운 네트워크 조회, 점수, 목표가 산식은 없습니다.
- 기존 `render_entry_execution_plan`을 한 번 실행한 반환값을 재사용합니다.
  종목/현재가/목표/손절이 원판정과 불일치하면 가격 제시를 보류합니다.
- `precision_observation.duration_observation`: 기존 관측봉 계산을 공용화하고
  실제 확인봉 존재 여부를 함께 반환합니다. 기간만으로 조정 충분 또는
  에너지 축적을 판단하지 않습니다.
- 새 모듈을 정밀관측소 빌드 진단 목록에 포함합니다.

## 정합성 보호

- 현재 채널은 같은 일봉의 가격·레일·알려진 시점으로만 비교합니다.
  종료된 채널, 미확정 봉, 미래 확인 시각, 오래된 거래일은 구분합니다.
- 기대 완료 거래일과 판정 기준일이 마지막 관측봉과 맞지 않으면 현재
  지지/저항으로 안내하지 않습니다. 과거 마지막 매도 이벤트도 현재의
  확정 이탈로 부르지 않습니다. 종료 채널의 실제 최신 매도 신호는 별개입니다.
- 상위 주·월봉이 진행 중이면 잠정 해석으로 표시합니다.
- 기간의 확인봉 또는 현재 거래량/MFI 근거가 없으면 A안이 성립했다고
  표시하지 않습니다. 자료 존재가 반등 우위나 확률을 증명하지는 않습니다.
- 거래량·MFI·추정 매물대는 대용치입니다. 실제 대기 손절 주문, 참가자 의도,
  유동성 사냥 완료, 검증된 승률은 표시하지 않습니다.
- 원계획의 강세 시나리오 상단은 확정 목표가로 바꾸지 않습니다.
