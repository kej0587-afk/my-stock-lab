## 수정 범위

- 가격·지표·판정은 재계산하지 않는다. 기존 생성 표의 실제 숫자 셀을 읽는다.
- 본문/상세 근거/미연결을 구분하고, 미연결이 관측실 조회 실패라는 뜻이 아님을 밝힌다.
- 이름 또는 티커가 문장에 등장하거나 미연결 행이 있는 것만으로 성공 처리하지 않는다.
- 0은 실제 숫자이고 NaN/inf/빈칸/미수집은 숫자가 아니다. 원래 날짜·출처·지연 경고는 해당 표에 그대로 둔다.
- 하이일드와 실업률은 기존 지표의 명시적 별칭만 사용한다. 추정 지표/유사 통계 대체 없음.
- 관측실 표를 한 번 준비해 본문과 연결 상태에서 재사용한다. 외부 요청·캐시 TTL 변경 없음.
