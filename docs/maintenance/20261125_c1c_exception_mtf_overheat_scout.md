# C-1c C안: 상승장 EXCEPTION_ENTRY 상위시간대 과열 1/3 정찰 (2026-11-25)

사용자 결정(2026-11-25, C-1c 비교 후 C안 채택): 상승장 EXCEPTION_ENTRY에 한해, 상위시간대가 '추세훼손'이 아니라
'상승 과열(정찰만 적합)'일 때 1/3 정찰 실행을 허용합니다. "상위시간대 과열이면 안전하다"는 뜻이 아니라, 정찰 진입으로
설계된 코드가 상승장에서 과도하게 차단되는 경우에만 작은 탐색 진입을 허용하는 정책입니다.

비교 보고서: `/mnt/project-files/reports/20261125_c1c_mtf_overheat_scout.md`

## 규칙표

| 항목 | 규칙 |
|---|---|
| 대상 | 미보유 `EXCEPTION_ENTRY`만. NEW_ENTRY_LEADER, LEADER_MA5, 52주 돌파, 일반 눌림, 우량주 회복은 현행 |
| 장세 | 2단계에서 정한 상승장(SPY/KOSPI 종가 > 200일 평균, 200일 평균 20일 상승)만. 횡보·하락·미확인은 현행 대기 |
| 상위시간대 | `정찰만 적합`(주봉/월봉 상승 과열권)일 때만 예외. 주봉·월봉 중 하나라도 추세훼손이면 기존대로 `MTF_DAMAGE_NO_ADD` 방어 |
| 동작 | `MTF_OVERHEAT_SCOUT_ONLY`로 바꾸지 않고 `EXCEPTION_ENTRY`를 유지, `mtf_overheat_scout=True` 표시 |
| 사이징 | 목표비중의 1/3 정찰(1단계와 같음). 2차·3차는 새 신호 확인 후 재계산 |
| exit | 1단계 추세추적(초기 진입가-2ATR, 최고 종가-3ATR 추적) |
| 그대로인 게이트 | R/R ≥ 1, 시장방어, 매크로 하드가드·미확인, 비중, 데이터확인, 과열 코드, 패턴, 돈흐름 |
| 월간 리밸런싱 배율 | 변경 없음 (리밸런싱은 MTF 가드 이전 엔진 판정을 읽음) |

## 화면 표시 (일반 실행가능과 구분)

- 게이트 근거: `정찰 실행: 1/3만 허용 (상승장 + EXCEPTION_ENTRY, 상위 시간대 추세훼손 아님)`
  (1단계 일반 예외승인 실행은 `정찰 실행: 1/3만 (EXCEPTION_ENTRY 추세추적)`)
- 오늘 큐: 실행메모 `정찰 실행(1/3) · 추세추적`, 기술적 타점에 `/ 정찰 실행(1/3)`, 핵심근거에
  `상위 시간대 상승 과열: 상승장 예외승인만 1/3 정찰 허용(추세훼손 아님)`
- 정밀관측소 실행 계획: 상태 `정찰 실행(1/3) · 상위과열 예외`, 설명에
  `현장소장: 예외승인 정찰 진입 / 상위시간대: 상승 과열 / 실행판단: 1/3 정찰 허용 / 사유: 상승장 + EXCEPTION_ENTRY, MTF 추세훼손 아님`
