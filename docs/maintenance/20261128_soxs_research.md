# SOXS 차단 원인과 단기/헤지 연구

## 결론
운영 차단 유지. 짧은 계좌 모형에서 헤지 효과가 있었지만, 더 긴 표본의 단기매매·반도체 집중
포트폴리오에서는 손익과 낙폭이 악화됐다. 수익률로 신호/보유기간/비중을 최적화하지 않았다.
과거 매크로/실제 계좌 거래이력은 복원하지 못했으므로 현행 정책 대안의 확정 검증은 아니다.

## 실제 운영 판정 (11/28 01:43KST)
직접 정밀관측소에 SOXS 자유탐색 입력, 검토 ZIP 내려받음. 빌드97a17e6b/restart_required=False.

| 구분 | 확인된 적용 경로 | 상태 |
|---|---|---|
| 상품 | ETF·레버리지/인버스; 포트폴리오 노출 −3배 | 정상 분류 |
| 공통 시장방어 | 시장실행상태=레버리지 시장방어, 최종 게이트=방어우선 | 인버스 예외 없음 |
| SOXL용 조건 | main_decision.leveraged_precision_profile=SOXL, 회복3/6, 기초축1W평균−2.4% | **상품명 fallback 오연결 확인** |
| 자체 타이밍 | LEVERAGED_WATCH_NO_POSITION; 미보유 관찰, R/R1.07 | 미보유 타점관찰 |
| 비중/금액 | target_w=0; 목표비중 미설정·금액 미설정 | 시장 차단과 별도 제한 |
| 현금·자료 | 핵심 가격/회복 자료 수신; 해당 종목 목표금액 없음 | 현금 부족으로 단정하지 않음 |

오연결 위치: app.py `get_leveraged_etf_precision_profile`가 상품명 DIREXION/SEMICONDUCTOR/3X로
SOXL을 반환하고 BEAR를 제외하지 않는다. ticker만 SOXS일 때와 실제 전체 상품명이 있을 때 결과가 다르다.
운영 ZIP에서 실제 SOXL프로필과 SOXX기초축 표까지 확인했다. 분류는 asset_classifier,
시장 차단은 decision_workflow.attach_market_execution_context, −3배 노출은portfolio에 있다.
**사용자가 연구 후 운영 정책을 결정하기로 했으므로 이번에 프로필/회복/L3/차단을 변경하지 않았다.**
개인 원본은 Downloads/precision_review_SOXS.zip에만 보존, Git 제외.

## 사전 고정한 연구 방법
- scripts/soxs_research.py는 운영에서 import하지 않는 오프라인 연구 코드.
- Yahoo 실제 SOXS/SOXX/SPY 조정 OHLC, 2024-01-02~2026-11-25. 분할·배당 조정은 공급처에 맡기고 이중 가산 안 함.
- **시장방어 대용**: 종가 SOXX<20일평균 AND SPY<50일평균. 실제 과거 매크로 점수/L3 재현이 아님.
- 신호 다음 거래일 시가 진입, 진입일 포함5거래일 종가 청산, 겹치는 보유 없음.
  최초자본5% 한도/남은 현금 범위. 동일시각 신호로 당일 종가 체결하지 않는다.
- 기본 편도 수수료5bp+슬리피지10bp(왕복30bp), 비용2배(60bp) 민감도. 실제 증권사 비용이 아닌 연구 가정.
- 현금 수익0, 세금/이자/환전수수료 미반영. 종료일 미완료1건은 완료거래 통계에서 제외하고,
  계좌 전체기간 비교에는 **마지막 실제 종가와 매도비용으로 가상청산**하여 별도 mark_to_market 집계.
- 낙폭은 일별 종가 계좌곡선 MDD, 장중 최대낙폭 아님. 최대 거래손실은 완료된5일 거래 손실.
- SOXX가 당일 반등했지만20일선 아래인 날도 포함. 신호136일 중 상승일60일, 완료거래36건 중10건.
- 미국 거래소 세션으로 보유일 계산. 자료 누락을0이나 임의시세로 채우지 않으며, 누락 경로 성과는 보류.
