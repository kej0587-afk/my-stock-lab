# 시황 보조 종가 검증의 미국 단축장 경계 수정

시작 커밋 `ce54e1eb`, 깨끗한 main에서 진행. 이번 범위는
`report_quotes.regular_quote_observation` 한 경로다.

## 원인과 수정

기존 검증은 정규장 종가를 항상 16:00 ET로 가정했다. 거래소 달력에는
2026-11-27 마감이 13:00 ET인데 13:00:04의 정상 quote를 13:20에도 거부했다.
[NYSE 공식 일정](https://www.nyse.com/trade/hours-calendars)과
[ICE/NYSE 2026 공지](https://ir.theice.com/press/news-details/2025/NYSE-Group-Announces-2026-2027-and-2028-Holiday-and-Early-Closings-Calendar/default.aspx)로
11/26 휴장, 11/27 13:00 조기 마감을 대조했다.

- 기존 `report_exchange_clock.session_on_date`로 최근 완료 세션 두 개를 구한다.
  이미 캐시한 연도별 달력을 재사용하며 추가 원격 조회와 TTL 변경은 없다.
- 실제 마감 전 quote는 종가로 확정하지 않는다. 마감 후 15분 유예 중에는
  마감 이후 시각을 요구하고, 이후에는 직전 1분의 마지막 체결도 허용한다.
  기존 분 단위 허용 경계(마감+15:59 포함)를 유지한다.
- 휴장/주말/연도 변경 시 실제 직전 거래일을 사용한다. 달력 미확인은 거부하며
  평일 추정으로 보충하지 않는다. 역방향 검색은 32일로 제한한다.
- 종목·가격·시각·부호 검증, 이력 복구의 조정기준/OHLC 검사, 기존 일봉 보존,
  시간외 세션 정의, 점수·판정·표시 문구는 유지한다. 호출자의 자료도 불변이다.

## 검증

- 선택 보고서 gate 전 **208 통과 / 47.840s** (`report_ps1ctilw`),
  후 **208 통과 / 48.214s** (`report_0oe6dzri`). golden 재생성 없음.
- 신규 경계 47건을 포함한 관련 테스트 **137 통과 / 10.15s**.
  정상장(DST 전후), 단축장, 추수감사절, 주말, 연도 경계, 유예, 미래/이전 quote,
  달력 실패, 가격 조정 불일치, 원본 불변, 시간외 분리를 검사했다.
- 수정 전 함수와 동일 입력의 정상장 반환값 **128건 완전 일치**.
  합성 11/27 13:00:04 quote는 수정 전 `{}` → 수정 후 날짜11/27,
  직전거래일11/25, 가격90/100, 수익률-10%로 복구된다.
  숫자는 테스트 입력이며 실제 미래 시세가 아니다.
- 운영 단축장 실시간 검증은 아직 불가능하다(현재11/21). 실제 운영에서는
  정상장11/20 종가 및 새 모듈 적용을 확인한다.
