# 오늘점검 새 세션 복원·시장방어 관찰

## 문제와 수정

기존 파일은 계산 결과와 계좌 서명만 보존했다. 새 브라우저에서 세션 전용 돈흐름
자동후보가 사라져 현재 목록92/저장104가 달라지고 전체104행이 자료확인으로 표시됐다.
저장 원계산의 오류104건이 아니라 입력 범위 복원 실패였다.

이제 기본/자동후보 목록·순서, 모드·재무revision, 계좌/보유/관심 맥락, 당시 돈흐름,
원계산 시각, 최종 표시표·시장guard·관찰근거를 계좌별 원자적 JSON 저장에 포함한다.
명시적 타입 codec으로 소수·빈값·자료형을 보존하며 pickle이나 실행 가능한 복원은 사용하지 않는다.

- 동일한 사용자 입력일 때만 자동후보를 복원하고 전체 서명을 다시 검증한다.
- 같은 종목 목록이어도 실제 돈흐름 값이 바뀌면 이전 표시표를 재사용하지 않는다.
  파생 섹터 표시 카드와 최상위 내부 캐시는 계산 입력 변화로 보지 않는다.
- 기존2시간 기준을 새 복원 유효성에 적용한다. 자료 공급처 TTL·조회 한도는 바꾸지 않았다.
- 복원 화면은 저장 시각을 유지하며 애널리스트/시장guard를 다시 조회해 섞지 않는다.
- raw 소수10자리 JSON은 관찰키 정밀도와 달랐다. 무손실 원표 저장으로 해결했다.
- 저장용 DataFrame attrs는 화면/CSV concat에서 분리하고 raw 저장본에만 보존한다.

## 모의 비교의 범위

새 계산에 한해 해결된 원엔진 분기 입력을 별도 sink에 복사한다. 원본 정책·최종 안전처리·
금액·사이징 문구를 먼저 재생하고 완전히 일치한 경우에만 storm guard 두 분기를 제외한다.
매크로 점수를0으로 치환하지 않으며 점수·기술조건·월적립률·비중·L3는 그대로 둔다.

이 비교는 **전체 매크로 영향 제거가 아니다.** 다른 매크로 조건은 유지된다. MTF·레버리지
후처리와 확정 실행금액/예산·증권사 주문가능액까지 재생한 것도 아니다. 예수금 입력은
실제 주문가능액으로 승격하지 않는다. 기존 자료 누락 행은 미확인/자료 부족이며,
운영 매수 허용·금액·월적립·L3에는 비교 결과를 쓰지 않는다.
