## 자료 표시·재사용

기준일 미확인과 거래종료를 구분하고, 원자료 누락·상장변경 근거를 표로
제공한다. 종료 행은 최신 세션을 결정하지 않는다. 예전 SQ 또는 종료 사유가
빠진 QRVO를 가진 테마 스냅샷은 같은 가격 날짜여도 재사용하지 않는다.

기존 `가격부족` 등 판정 어휘, 매매 점수·임계값은 유지한다. 추가된 상장상태와
근거는 자료 진단이다. 보유자산·관심목록·평단·수량·거래 이력은 수정하지 않는다.
사용자가 저장한 구티커의 전역 DB 변환도 하지 않았다.

## 실자료 대조

2026-11-01 공개 시세 조회에서 XYZ 일봉 251개, 실제 가격 기준일 2026-10-30,
종가 76.220001달러를 확보했다. 이는 Yahoo 공급 자료이며 독립 공급자 검증은 아니다.

기존 실자료를 고정하고 XYZ 가격만 보완해 재생했다. ETF 109행은 완전히 같고,
테마의 영향 없는 473행도 수치·판정이 같았다. 전체 테마 475행은 유지한다.
가격 미확보 행의 날짜 표현만 빈 문자열로 통일했다. 미국 테마 기준일 미확인은
2→0건, 거래종료는 1건이다. 이는 두 종목의 시세를 모두 복구했다는 뜻이 아니다.

QRVO의 반복 조회가 빠져 가격 프레임 경로 호출은 486→485개다. HTTP 호출 수로
해석하지 않는다. 추가 속도 개선율은 주장하지 않는다.

수정 후 별도 프로세스에서 전체 시세를 다시 조회했다. ETF 표 3.845초,
테마 표 10.979초, 합계 14.825초(로컬, 유니버스 구성·UI·로그인 제외)였다.
SQ·QRVO 요청은 없었고 전송 실패 속성은 없었다. 미국 기준일 미확인 0건과
거래종료 1건도 실조회에서 재확인했다. 이 값은 전체 Cloud 로딩시간이 아니다.

재현 도구: `tests/benchmark_flow_symbol_repair.py`.
무시 대상 공개 자료: `cache/flow_symbol_repair_20261101_*`.
대만·오스트리아 일부 원자료 미연결은 이번 미국 2건과 별도이며 정상값으로 채우지 않았다.

## 가장 큰 화면 함수

기준 커밋 `3160cd93`의 `render_portfolio_analysis_tab` 839줄을 185줄로
분리했다. 리스크 차트 337줄과 상세 평가 319줄을 같은 파일의 헬퍼로 옮겼다.
문장 트리·문자열 리터럴은 기존과 정확히 같으며, 매매 판단과 계산은 고치지 않았다.

이전 구현과 정상·고위험·자료부족·빈 자산·상세 보기·월별 기록·실행 전 경로의
전체 UI 호출, 표 값, Plotly JSON, 선택 키와 상태를 비교한 14개 테스트가 통과했다.
이 분리는 유지보수를 위한 것이며 자체 로딩 속도 개선을 뜻하지 않는다.

배포 중 새 앱과 이전 원자료 진단 모듈이 함께 남아도 ImportError로 죽지 않고
구체적인 재시작 안내를 표시한다. 실제 운영 모듈 적용은 검토 ZIP의 지문으로 확인한다.

## 검증 결과

전체 회귀 4,450개 통과·1개 건너뜀·하위 테스트 18개 통과(234.49초).
심볼·경계일·시각대·상장종료·재사용·집계 관련 집중 테스트도 통과했다.
독립 읽기 전용 리뷰에서 상장변경 연결의 추가 수정 필요 사항은 발견되지 않았다.
컴파일과 차이 검사도 통과했다. 운영 배포 검증은 이 테스트 시간과 구분한다.

운영 대조 중 재계산 전에 읽은 `마지막 계산` 시각이 한 번 이전 값으로 남는
표시 오류도 확인했다. 완료 후 새 시각을 읽도록 위치만 옮기고 같은 렌더링에서
신규 시각이 출력되는 회귀 테스트를 추가했다. 계산 결과·원자료 시각은 바꾸지 않는다.
종료일이 없는 일반 조회 실패의 날짜 칸은 `None` 문자열 대신 빈칸으로 표시한다.

후속 전체 실행에서는 기존 뉴스 관련성 테스트 1건이 간헐 실패했다. 반복 가짜
RSS의 발표시각이 매번 `now()`로 만들어져 초 경계를 넘으면 동일 매체 최신기사
정책이 다른 행을 고르는 테스트 입력 문제가 있었다. 동일 테스트의 발표시각을
고정했다. 운영 뉴스 선택 정책은 변경하지 않았으며 이 정책의 카테고리 간 우선순위는
별도 점검 대상이다.

최종 재실행은 4,451개 통과·1개 건너뜀·하위 테스트 18개 통과(234.89초).
운영 검토 ZIP(19번 다운로드, 런타임 커밋 `ebb2cfd0`)에서 앱 진입점·돈흐름·
상장변경·스냅샷 모듈의 로컬/디스크/로드 지문이 모두 일치했고 재시작 필요 표시는
없었다. 운영 금융 테마에서 XYZ·2026-10-30·76.220001달러도 대조했다.
통합판은 미국 테마 미확인 0건·거래종료 1건이고 기존 시장방어를 유지했다.
포트폴리오 누적 흐름·비중·상관관계 차트와 상세 평가 토글도 정상 표시됐다.
