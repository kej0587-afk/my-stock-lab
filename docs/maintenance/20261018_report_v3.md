# 자동 뉴스픽 3차 점검

## 변경 범위

- 발행용 리포트는 보유 종목 표 하나로 통합. 구형 오늘점검 나열 블록은 발행용 경로에서 제외.
- 시장 공통 판정은 맨 위 한 줄. 보유 표에는 비중초과/레버리지 보유/추세훼손/가격급락/데이터부족 등 고유 사유만 표시.
- 관심 종목은 상위 3개와 기존 해제 조건만 표시. 후보등급, 게이트, 매매 임계값은 변경하지 않음.
- 보고용 가격/매크로는 `collect_report_context`에서 한 묶음으로 수집. 기존 앱 실시간 매크로 `macro_res`로 누락을 대체하지 않음.
- 한국/미국 종가 기준일과 1개월 비교 시작일을 각각 표시. 동일 날짜 미국장과 한국장은 동시 세션이 아님.
- 379800/379810/418660은 다음 한국장 영향 추정, 실제 한국장 등락은 별도 열. 포트폴리오의 `infer_scenario_shock_multiplier` 재사용.
- BITX는 BTC 5분봉의 뉴욕 16:00 종료 가격 두 개를 비교. UTC 일봉이나 ETF 자체 등락을 다시 2배 하지 않음.
- 반도체 보유 시 SOXX/DRAM/XLK 및 보유 레버리지 움직임을 스토리 앞에 표시. PPI/고용은 단위 보정한 이전 대비 변화로 선정.
- 업종별 사실/해석(추정)/미확인 분리. RAM 등 레버리지는 업종 비교에서 제외.
- 웹 화면은 마크다운 표 유지. 텔레그램/카카오 발송이나 새 외부 계정 연동은 추가하지 않음.
- 기준 거래일 마감 후 2시간 이내의 당일 마감 회고는 사후보도로 명시해 기준일 뉴스에 포함한다.
  이전 거래일 마감 회고는 제외하고, 나머지 마감 후 뉴스는 다음 세션 재료로 분리한다.
  같은 시장/거래일 마감시황은 한 사건으로 묶는다. 정제기를 반복 통과해도 제목/채택 결과가 바뀌지 않게 검증했다.

## 전일 비교가 비어 있던 이유

기존 `today_snapshot.py`는 점검 계산 버튼의 실행 날짜(`last_run`)가 바뀔 때만 이전 자료를 보관했다.
리포트 생성은 저장을 하지 않았고, 로직 버전이 바뀌면 이전 자료를 읽지 않았다.
따라서 주말 재생성, 계산 없이 발행, 버전 변경/재배포에서 전일 비교가 비었다.

새 `report_history.py`는 리포트 생성 시 계정별 파일에 미국/한국 거래일 쌍으로 판정·게이트·사유를 저장한다.
동일 거래일은 덮어쓰고, 두 시장 모두 현재보다 늦지 않은 직전 저장분과 비교한다.
개인 계정은 해시로 격리하며 공개 데모는 저장하지 않는다. 첫 실행은 이전 자료가 없는 것이 정상이다.
로컬 파일은 Streamlit Cloud 재배포/컨테이너 교체 시 소실될 수 있다. 영구 보존용 Supabase 마이그레이션은 포함하지 않았다.

## 수치 및 외부 연결 확인

- 환율 1329.60과 1340.95: 기존 전달값에는 동일한 종가일/비교 시작일/수정 시각이 없어 과거 차이의 원인을 확정할 수 없다.
  코드상 리포트 앞부분과 하단이 서로 다른 매크로 경로를 사용한 것은 확인했다. 새 경로는 10/16 종가 1340.95,
  9/17 대비 -2.59%로 재현되며 모든 값에 기준일을 붙인다. 값이 바뀌었다는 사실만으로 정렬 효과라고 단정하지 않는다.
- [BLS 9월 PPI 원문](https://www.bls.gov/news.release/archives/ppi_10152026.htm): 전월비 SA +1.3%, 이전 +0.5%; 전년비 NSA +6.3% 확인.
  +6.3%는 높은 수치이지만 입력 오류로 고치지 않는다. 원문 확인 사실과 현재 API 값의 일치 여부만 표시한다.
- [BLS 9월 고용 원문](https://www.bls.gov/news.release/archives/empsit_10022026.htm): +29천명, 발표 10/2 08:30 ET 확인.
- [BLS 9월 CPI 원문](https://www.bls.gov/news.release/archives/cpi_10142026.htm): 발표 10/14 08:30 ET 확인.
- 위 과거 발표일은 출처를 붙인 검증 자료 파일에 보관. 다른 관측월의 날짜를 추정하는 데 사용하지 않는다.
- 이번 실제 HTTP 검사에서 BLS 일정 페이지/ICS는 403, Fed FOMC 페이지는 연결 성공. BLS 향후 일정은 미연결로 표시한다.
  미래 일정을 임의 생성하지 않는다. 발표일 시장반응은 검증된 날짜의 10Y/환율/나스닥 일봉을 비교하며 인과가 아니다.
- FRED/Census/ECOS 키는 미발급 상태. 코드가 키를 발급하거나 임의 입력하지 않는다. 설정은 `economic_api_setup.md` 참조.

## 성능 감사

사용자 제공 JSON의 오늘점검 실제 경과시간은 **117.601초**, 진입 전 **17.585초**, 실행 전체 **135.186초**다.
카테고리 누적 작업시간 합계는 **360.167초**로 실제 경과시간의 약 **3.06배**다. 병렬 중첩이므로 합산할 수 없다.
`load_display_live_price` 86.571초 안에 `load_latest_price` 86.567초가 포함되고,
`kr_quote_fallback` 76.840초 안에 실시간 네이버 조회 73.112초가 포함된다. 둘씩 더하면 이중 계산이다.
이전 JSON에는 호출 시작/종료 구간이 없어 정확한 타임라인을 복원할 수 없다. 현재 v2 계측의 구간 합집합 필드를 사용해야 한다.

기존에 가격 일괄 선조회와 한국 시세 4개 병렬 제한, 클러스터별 90초 캐시가 이미 존재한다.
이번에는 3개월만 워커에 전달하던 가격 프레임 범위를 1년/10년까지 중첩 재사용하도록 보완했다.
원본 프레임 복사, 기간별 데이터 경로, 판단 결과는 유지한다.
36개 클러스터가 모두 같은 입력인지는 집계 로그만으로 알 수 없어 무조건 1개로 합치지 않았다.
**배포 계정의 변경 후 elapsed_seconds는 아직 측정하지 않았다.** 샘플 리포트 생성 시간이나 모의 테스트 시간을 실제 오늘점검 개선율로 보고하지 않는다.

## 차트

차트 위에 품질/가치/성장/재무건전성/주주환원/모멘텀 성적표를 추가했다.
첨부 Pine의 선형 점수 범위를 가용 항목에 적용한 축약형이며 원본 전체 지표와 동일하다고 주장하지 않는다.
축별 결측 제외 평균과 자료 충족도를 공개하고, 기업 재무가 해당 없는 ETF는 점수를 만들지 않는다.
주주환원은 배당/배당성향/FCF만 연결, 자사주 매입·ROIC·Piotroski 등 없는 항목은 계산하지 않는다.
기존 4점 재무점수/매매 게이트와 완전히 분리했다.
거래량은 현재 봉 해설, 평균 거래량/대금/Buzz/U-D 표, 색상별 의미를 함께 표시한다.

## 검증

- 표 통합, 국내 미국자산 ETF 갭, 미국장 마감 BTC, 동일일 금리 bp, 미래/주말 매크로 제외, 거래일별 비교/계정 격리 테스트.
- 같은 날짜 재생성으로 직전 거래일이 사라지지 않고 사유만 달라져도 비교에 표시되는지 검증.
- 실제 API/시세/RSS로 `docs/samples/market_report_20261018_v3.md` 생성. 보유목록/비중은 명시된 예시이며 실제 계좌가 아님.
- 배포/커밋/실제 매매/메시지 발송은 하지 않음.
- 전체 회귀 테스트 1,136개 통과. Streamlit 웹 미리보기에서 표/차트 성적표/거래량 해설 렌더링 확인.
