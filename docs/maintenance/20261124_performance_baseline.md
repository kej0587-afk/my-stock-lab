## 왜 이 조건인가

지금까지 기록(오늘점검 95~107초, 시황 79~127초)은 캐시·원격 응답 상태가 제각각이라 서로 비교할 수 없었다.
앞으로 속도 비교는 아래 **한 가지 조건**으로만 한다. 다른 조건의 숫자로 개선·악화를 주장하지 않는다.

**조건 A(재부팅 직후 첫 실행):** share.streamlit.io에서 Reboot → 앱 첫 화면 로드 → '✅ 오늘 점검'에서
"오늘 종목 점검 계산/새로고침" 1회 → 끝나자마자 '시황'에서 "자동 뉴스픽 생성" 1회. 같은 계좌, 다른 화면 조작 없음.
시간은 앱 화면의 "화면 처리 완료 · N초"와 "직전 실행 … N초"를 그대로 옮긴다.

주의: 재부팅은 앱 프로세스 캐시만 비운다. Supabase 저장값과 외부 공급처 캐시는 남으므로 "완전 무캐시"가 아니다.
장중/장마감, 요일, 뉴스 양에 따라 원격 응답이 달라지므로 같은 시간대(한국 장중 등)끼리만 비교한다.
