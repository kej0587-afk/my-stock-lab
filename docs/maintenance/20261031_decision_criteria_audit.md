# 시장 위험 판정과 매매 기준 검토

2026-10-31 운영 자료와 현재 코드를 함께 검토했습니다. 시장 위험에 따른 신규·추가매수 중단은 기존 규칙으로 재현됩니다. 다만 결측 처리, 손익비 반올림, 코드명 해석, 보유 설명에서 확인된 오류는 수정했습니다. 기존 판정명과 위험 임계값은 유지합니다.

## 현재 시장 위험의 근거

한국과 미국 기준 지수 10개 모두 2026-10-30 일봉으로 정렬되어 있습니다. 이번 시장 위험은 오래된 날짜 또는 장후 등락률의 혼입으로 설명되지 않습니다.

| 구성 | 실제 가점 | 근거 |
| --- | ---: | --- |
| 지역 점수 최대값 | 7 | 한국 7, 미국 5 중 큰 값 |
| 가격·거래량 흐름 | 2 | 3M 양수 비율 18.2%가 35% 미만. 가속 양수 비율 36.4%는 추가 가점 없음 |
| 매크로 | 2 | 금리·MOVE·유가 부담의 가중 합계 4 |
| 이벤트 직접 가점 | 0 | 원래 1점이지만 지역 점수 5 이상에서는 직접 합산하지 않음 |
| 복합 부담 | 1 | 지역 5 이상이며 매크로 2 + 이벤트 원점수 1이 3 이상 |
| 합계 | **12** | 8 이상은 위험, 신규·추가매수 중단 |

한국 7점은 MA20 하회 +2, MA50 하회 +2, 5일 -3% 이하 +2, 당일 -1.5% 이하 +1입니다. 미국 5점은 MA20 +2, MA50 +2, 당일 급락 +1입니다. 실제 서킷브레이커 발동을 확인한 판정이 아니며, 현재 -8%/-5% 급락 지수에 의한 비상 조건도 없습니다.

보유 위험 점수 4를 합친 16은 별도 참고값이며 시장 모드를 결정한 값은 12입니다. 리포트 스트레스 66도 다른 0~100 산식입니다. 서로 같은 점수처럼 비교하면 안 됩니다.

| 화면 설명 | 통합 위험에서도 정상 지역은 따로 매수 가능한 것처럼 설명 | 통합 중단 우선순위를 명시 |
| 보유 설명 | 보유 적합성의 분할매수 가능 문구가 실행 허가처럼 읽힘 | 원문 보유 평가는 보존하되, 현재 실행 보류와 사유를 앞에 명시 |

이 오류들이 현재 12점의 원인이라는 뜻은 아닙니다. 기존 내보내기에는 흐름 결측 개수가 없어 실제 영향은 새 계산의 유효 표본과 비교해야 합니다. 입력이 완전한 경우 기존 위험 가점은 동일합니다.

## 유지한 판정 구조

후보 품질은 살펴볼 가치, 기술 타점은 현재 진입 조건, 실행 게이트는 시장·비중·데이터·추세·손익비 제한을 나타냅니다. 좋은 후보이면서 실행 보류인 것은 가능한 조합입니다. 최종 매수 허용은 실행 게이트를 따라야 하며 보유 적합성만으로 대체할 수 없습니다. 신규매수 중단은 기존 보유 전량 매도 지시가 아닙니다.

R/R은 구조 목표가 또는 +4ATR 투영상단과 2ATR 손절의 비율입니다. 승률·슬리피지·수수료가 포함된 기대수익률이 아닙니다. 투영상단의 R/R 2는 독립된 목표가나 수익 보장이 아니며 기존 대기 규칙을 유지합니다.

## 후보 등급의 실제 산식

| 구성 | 현행 점수 |
| --- | --- |
| RS | 강함 2 / 보통 1 / 그 외 0 |
| MFI | 30 미만 +2 / 80 초과 -1 / 그 외 0 |
| 추세 | 정배열 +2 / 그 외 0 |
| MACD | 골든크로스 +2 / 상승 유지 +1 / 데드크로스 -2 / 그 외 0 |
| SQZ | 해제 직후이면서 MACD 상승 조건 충족 +1 |
| 개별주 재무 | 위 기술 합계에 재무점수 추가. 재무 1이면 F 우선 |

개별주는 합계 7 이상 A, 9 이상 S입니다. ETF는 재무점수를 더하지 않고 기술 합계 3 이상 양호, 5 이상 우수입니다. 낮은 등급의 재무 우선 예외는 원래 코드대로 유지합니다.

따라서 현재의 후보품질은 순수한 기업 품질 점수가 아니라 **재무와 기술을 혼합한 후보 점수**입니다. 별도 Adj점수는 진입 점수·RS·MFI·RS 기울기에서 매크로 감점을 뺀 값입니다. 후보등급, Adj, 실행 게이트를 같은 수치처럼 읽으면 안 됩니다. 재무 품질과 타점을 완전히 독립시키려면 별도의 설계 변경과 검증이 필요합니다.
