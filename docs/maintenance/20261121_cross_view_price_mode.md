2. 자유입력으로 보유 종목을 검색해도 `has_position=True`일 수 있다. 오늘점검은
   `is_free=False`, 정밀은 실제 선택 유형을 사용한다. 같은 고정 KR ETF 입력에서
   계좌 경로의 비중 초과 차단과 자유입력 경로의 다른 코드가 재현됐다.
   가격·품질점수·비중은 동일하다. 이를 새로운 정책으로 통일하지 않는다.
3. 실제 호출 모드·보유 여부·선택 유형을 `input_basis`의 표시 근거로 기록해
   오늘점검 상세·정밀 근거 표·검토 ZIP·포트폴리오 저장 경로에 전달한다.

   바꾸지 않는다. 두 자료가 모두 없으면 빈 표도 추가하지 않는다.
