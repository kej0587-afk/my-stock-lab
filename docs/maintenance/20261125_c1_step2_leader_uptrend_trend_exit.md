# C-1 2단계: NEW_ENTRY_LEADER 상승장 추세추적 exit (2026-11-25)

사용자 결정(2026-11-25): 대장주는 ②번 방향. 상승장에서만 추세추적 exit, measured move는 어떤 장세에도 쓰지 않음,
하락장은 현행 보수적 진입 제한 유지. "추세추적 방식의 구체적인 게이트·exit 정의는 구현 전 명확한 규칙표와 테스트를 만들어
주세요"에 따라 아래 규칙표와 테스트를 먼저 두고 구현했습니다. 1단계(EXCEPTION_ENTRY, PR #40)와 같은 exit 정의를 씁니다.

## 재생 차이

### 넓은 표본 (C-1 144종목, 5거래일 격자, 엔진 코드 NEW_ENTRY_LEADER 1,990건)

새 코드로 1,990건을 다시 돌렸습니다. 엔진 코드와 MTF 이후 코드는 전부 같고, 게이트는 "상승장 = C-1의 B_trend,
그 밖 = 현행 A"와 1,990건 모두 일치합니다. exit 열은 상승장 실행 건은 추세추적, 그 밖은 현행 피벗 목표 기준입니다.

수익률 열은 신호일 종가 보유 기준이라 exit와 무관하며, 실행 건이 7건 늘어 조금 바뀝니다. 상승장 추가 7건은
투영상단(+4ATR) 목표 때문에 대기하던 건입니다. 남은 대기는 대부분 상위과열 정찰 전환(C-1c에서 비교)과 R/R<1입니다.

### 기존 parity 재생 (41,391 상태, 10거래일 격자)

1단계 적용 상태와 비교해 41,391건 모든 열이 같습니다(게이트 변화 0). 이 표본의 미보유 대장주 중 상승장에서
투영상단 때문에 대기하던 상태가 없었기 때문이며, exit 변경은 parity 열(코드·금액·게이트)에 나타나지 않습니다.
