## 무엇을 옮겼나

- `report_evidence.report_sections`(489줄)의 맨 앞 "## 기준일" 블록을 `_basis_lines(context, sessions, states, now, missing)`로 옮겼다.
  담당: 보고서 모드, 시장별 확정 종가 기준 표, 가격 기준 메모, 시차 안내, 입력 집계 문구.
- 종가 기준일이 없을 때 `missing`에 추가하던 동작은 같은 리스트를 넘겨 그대로 유지한다.
- `report_sections`는 이후 단계에서 쓰는 `kr, us`를 계속 직접 계산한다.
- 문장·순서·표 모양은 바꾸지 않았다(코드 줄을 그대로 옮김).
