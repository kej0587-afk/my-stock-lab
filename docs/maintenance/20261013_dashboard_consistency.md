# 시작 오류와 화면 일관성 정리

## 시작 오류

`app.py`가 새 `fetch_yahoo_display_metadata`를 일괄 import하면서 이전 `prices.py`와 조합될 때 시작하지 못하는 경로를 제거했다. 선택 import와 동일 종목 확인을 하는 구버전 대체 경로를 추가하고, 실제 함수가 없는 모듈을 대상으로 회귀를 검증했다. 제공된 redacted traceback만으로 다른 배포 오류까지 확정하지는 않는다.

배포할 때 `app.py`뿐 아니라 변경된 `stock_lab_core` 파일도 같은 Git 버전으로 반영해야 한다. 로컬 수정만으로 Streamlit Cloud가 갱신되지는 않는다.

배포 파일: `app.py`, `stock_lab_core/money_flow.py`, `stock_lab_core/market_memo.py`, `stock_lab_core/kiwoom_data.py`, `.streamlit/config.toml`. 이전 `prices.py` 보완 파일도 저장소 버전에 포함해야 한다. `.streamlit/secrets.toml`은 배포 코드에 포함하지 않는다.

## 통합 화면

- 돈흐름 기본 화면이 오늘점검과 동일한 저장 스냅샷 및 렌더러를 사용한다. ETF·테마 원자료와 키움은 선택한 화면만 렌더한다.
- 기본 주도 섹터 표, 리서치 카드, 능력치 그래프가 동일 점수와 시장별 순위를 사용한다. 중기 클러스터 원자료 순위는 별도 상세 정보다.
- 오늘 브리핑은 보유관리·시장·뉴스·시황·키움으로 구분했다. 중복된 뉴스/시황 UI를 제거하고 기존 공통 패널을 연결했다.
- 어두운 배경과 기본 밝은 테마가 섞여 캡션·선택지의 글자가 흐려지는 문제는 `.streamlit/config.toml`의 dark 기준으로 맞췄다.
- 미국 소비재의 자동차·여행 대표주를 뷰티로 표시하지 않도록 섹터 제목을 바로잡았다.

## 단기 지표

가격 원자료에서 1D와 5D를 별도로 산출하고 ETF, 테마, 하위테마, 통합 후보 행에 전달한다. 같은 섹터 점수 안에서 5D와 2W 수익률을 평균하지 않는다. 단기 자료가 없으면 사용한 대체 기간을 표시한다.

3M이 강해도 5D 하락인 테마·클러스터·통합 후보가 진입/정밀관측으로 다시 승격되지 않도록 제한한다. 기존 극단과열 우선순위와 투자 판정문구 정의는 유지한다.

운용사 자료로 확인한 [SOL AI반도체소부장 455850](https://www.soletf.com/ko/fund/etf/210980?tabIndex=1)을 국내 원천 ETF 및 반도체 클러스터에 연결했다. 해외 AI ETF 456600은 국내 반도체 클러스터에서 제외했으며, 원천 목록에서는 유지한다.

## 시황과 키움

시황의 한국/미국 단기 목록과 평균 분모를 분리하고 동종 지수·ETF 중복을 제거했다. 가격 등락을 실제 자금 유입/헤지 수요로 확정하지 않는다. 보유/관심을 분리하고 하드차단·비중초과 위험 목록의 상한을 제거했다. 확인하지 못한 사이드카·순매매를 추정 수치로 채우지 않는다.

키움은 비밀값 없이 설정 상태·실전/모의 환경을 표시하고 클라이언트 재확인 버튼을 제공한다. 기존 두 키 표기 호환과 모의 자료 제외를 유지한다. Secrets 변경은 서버 재시작이 필요하다. 사용자 키 인증과 Cloud 허용 IP는 실제 배포 환경에서 확인해야 한다.

## 검증 범위

구버전 import, 순위 결정성, 단기 기간 분리, 하락 테마 재승격, 극단과열 우선순위, 키움 비밀 비노출과 잘못된 환경값, 숨겨진 원자료 화면의 미실행을 회귀로 검증한다. 판정문구 golden을 포함한 전체 테스트와 로컬 체험모드 화면도 확인한다. 실사용 계정 저장·매매·Cloud 배포 또는 사용자 키 인증을 수행하지 않는다.

전체 테스트 758개 통과. pykrx deprecation 경고 1개가 남는다. 브라우저에서 시작·브리핑 메뉴 전환과 체험모드 키움 안내를 확인했다. 사용자 키로 실전 인증하거나 계좌 데이터를 저장하지 않았다.
