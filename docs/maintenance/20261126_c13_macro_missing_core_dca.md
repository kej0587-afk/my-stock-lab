# C-13: 매크로 결측일 코어 정기적립 비교 (2026-11-26)

분석만 했습니다. 정책·게이트·코드는 바꾸지 않았습니다. 사용자 결정 전입니다.

## 0. 요약
- **현행(A-5/A-6)**: 핵심 매크로(10년물, VIX, USD/KRW, 유가) 중 하나라도 없으면 Today 게이트가 `데이터확인 · 매크로 미확인`이 되고, 월적립도 그날은 집행되지 않습니다.
- **실제 결측 이력은 없습니다.** 운영은 결측일을 따로 저장하지 않고, C-2 재구성 시계열(2006–2026)에도 결측일이 없습니다. 그래서 아래는 "그날 매크로가 없었다면"이라는 가정 재생입니다.
- **짧은 결측(1일)**: 다음 확인일로 넘어가므로 손해가 작습니다. 매달 월초 하루씩 빠져도 집행률은 96.3%에서 94.5%로 줄어드는 정도입니다.
- **한 달 내내 결측**: 현행은 그 달 적립이 0입니다.
- **허용안(B)**: 코어 ETF의 허용 5개 코드에서 매크로 미확인 조건만 빼고 나머지 차단(시장방어·추세훼손 예외 규칙·데이터·비중 등)은 그대로 둡니다. 이렇게 하면 결측이어도 정상일과 거의 같게 집행됩니다(96.9%).
- **허용안의 위험**: 실제로는 퍼펙트스톰(4.5 이상)이었던 날이 결측으로 가려지면, 엔진이 매크로 중립으로 계산해 낙폭 배율(1.0~2.0)을 줍니다. 원래는 STORM 0.25~1.0이고 대부분 막혔습니다.
  - 그런 날 허용안은 27%를 집행했고(실제 매크로로는 5%), 금액은 원래 계획 합의 1.7배였습니다(31.75 → 54.0).
  - 이 표본(2008–2026)에서는 그 매수의 이후 수익이 평균 +3.6%(20일), +7.5%(60일), +14.9%(120일)였습니다. 60일 최악은 −11.4%였습니다.

## 1. 방법
- C-8/C-9 재생과 같은 조건입니다: 코어 ETF 6종, 2008–2026, 매월 0·5·10·15번째 거래일 확인, 월 예산 1, 같은 평단 경로.
- 결측 재생: 모든 확인일에 매크로 위험·패널티를 NaN(UNKNOWN)으로 넣고 엔진 → 상위 시간대 가드 → 판정 흐름 → 시장 가드 → 실행 게이트 → 월적립 규칙(코어 C2 + 추세훼손 예외)을 그대로 돌렸습니다.
  - 시장 가드는 결측일이라 매크로 위험(4.5/3.5) 점수를 빼고, 지역 지수·매크로 지표 압력·이벤트 점수로 다시 계산했습니다.
- 안:
  - **A 현행**: 결측일은 데이터확인으로 집행하지 않음.
  - **B 허용**: CORE_PULLBACK/NEUTRAL/OVERHEAT/DRAWDOWN/CRASH_DCA에서 `매크로상태 UNKNOWN` 한 조건만 빼고 게이트를 다시 계산(추세훼손 예외 D와 같은 구조). STORM·PANIC·개별주·레버리지는 해당 없음.
  - **C 허용 + 상한**: B와 같되, 결측일에 정한 월 계획 배율을 1.0으로 제한.
- 결측 기간 가정: 매달 월초 1일 / 월초 1주(0·5번째 확인일) / 한 달 전부. 모든 달에 결측이 있다고 둔 최악 가정입니다.

## 4. 재현하지 못한 조건
- 운영의 실제 결측 빈도와 지속 시간(기록 없음). 결측이 몇 시간인지, 며칠인지에 따라 A의 손해가 크게 다릅니다.
- 시장 가드의 돈흐름 점수와 전술 반등 판정(0으로 둠). 결측일에 매크로 지표 압력 칸까지 함께 비는 경우는 반영하지 않았습니다(이번에는 지표 압력은 있다고 가정).
- 실제 계좌 상태: 비중 5/15 고정, 수수료·세금·현금이자 0.

## 5. 사용자 결정 항목
- (a) **현행 유지**: 결측일은 멈춤. 짧은 결측은 다음 확인일에 집행되므로 손해가 작습니다.
- (b) **허용**: 허용 5개 코어 코드에서 매크로 미확인만 빼고 재계산합니다. 다른 차단은 그대로입니다.
- (c) **허용 + 결측일 배율 1.0 상한**: 스톰을 배제할 수 없는 날 2.0·1.5배가 나가는 것을 막습니다.
- 권장: (c). 긴 결측에서도 적립이 끊기지 않고, 가려진 스톰에서 배율이 커지는 위험은 1.0으로 묶습니다.
  다만 국장 코어는 실제 스톰 배율(0.25~0.5)보다 여전히 큽니다. 국장 코어만 0.5 상한으로 두는 안도 가능합니다.
- 결정과 별개로, 운영 결측일을 기록하면(날짜·빠진 항목·지속 시간) 다음 판단에 실제 이력을 쓸 수 있습니다. 이번에는 만들지 않았습니다.
