# 기업·시장·업종 연결 계약 정리

## 원인과 변경

- 시작 clean `058dcd6f`, fetch한 main과 동일. 운영 소스 수정 없음.
- 수정 전 해당 파일13통과/1실패(7.32초). 실패는 `9f4451ed`의 app 전체 함수 AST와
  현재 코드의 동일성을 요구해, 이후 승인된 시세·판정 입력 연결 변경도 거부한 검사였다.
- 이 한 검사를5가지 입력으로 교체: 반도체/통신 업종 연결, 업종 미등록 기업,
  다른 계좌의 자료, 수집 후31분 지난 자료. 업종 초과수익 −2/+2%p 및 미연결을 확인한다.
- 실제 `app.render_today_market_memo_panel`을 기업 심층분석 분기로 실행한다.
  기업 renderer 경계에서 계정·선택목록·업종 매핑·callback 전달을 검사하고,
  실제 계좌별 근거 선택기와 시장 해석 생성/표시 함수를 실행한다.
  전체 기업 UI 동작은 기존 AppTest로 별도 확인한다(운영 브라우저 검증과는 다름).
- 자료가 없거나 오래돼도 기업 재무 근거를 유지하며, 잘못된 시장 근거로 채우지 않는다.
  외부 시장/SEC/DART 재조회는 금지, 소켓 차단 유지. 합성 시황·관심목록·재무점수·오늘점검 표와
  서명이 변하지 않는지 검사한다. 조회 기준 시각은 고정하고 운영 TTL은 바꾸지 않는다.
- 기존20개 시나리오의 전체 판정 출력을 연결 전후 비교한다. 기존 golden 검사는 유지하며
  golden 재생성·실패 skip·새 투자 기준 추가 없음.
